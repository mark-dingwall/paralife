# Phase 19.1 Plan 02: F4/CE/TX RNG-Determinism Fixes Summary

Closed all three RNG-determinism HIGHs (F4/CE/TX). Same root pattern in all three: seeded RNG consumed in ConcurrentHashMap iteration order (non-deterministic) or via an unseeded `new Random()`.

### Task 02d: Determinism tests (commit bf14367)

**Final-state digest format:** sorted `TreeMap<entityId, List<ActiveBuff>>` for multi-cure; sorted member energy arrays for multi-composite; per-seed path equality for multi-toxin.

**Seed source used:** `environmentEngine.resetForTest()` re-seeds `rng` from `config.seed()=42`, so both runs start from the same deterministic state. No `spawnRng` involved — `rng` is the single source for the env engine.
