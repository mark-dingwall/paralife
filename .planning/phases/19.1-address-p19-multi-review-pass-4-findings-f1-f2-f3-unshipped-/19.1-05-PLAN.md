    **A5.5 amendment — public-surface-only design (Option b).** `drainActions` is `private`. Adding a `simulateOverwriteAfterDrainSnapshot` test-only seam to production code couples the production class to test-specific machinery and makes the drain implementation harder to refactor. The pinned semantic is observable from the public surface alone:

    - `queueAction(sessionId, action)` is the only mutator (concurrent-safe, public).
    - `drainActions()` is exercised via the tick pipeline (`processActions` @Order(20) — call `tickEngine.tickOnce()` to fire it).
