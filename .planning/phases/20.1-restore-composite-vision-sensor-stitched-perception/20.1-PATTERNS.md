```java
// src/main/java/com/paralife/bot/HeuristicBrain.java lines 299–318
private static DirectionInfo toDirectionInfo(CellEntry cell) {
    switch (cell.coord()) {
        case Coord.Numpad n -> {
            Direction d = Direction.fromNumpad(n.digit());
            return d == null ? null : new DirectionInfo(d, 1);
        }
        case Coord.Relative r -> {
            if (r.dx() == 0 && r.dy() == 0) return null;
            Direction d = fromDxDy(Integer.signum(r.dx()), Integer.signum(r.dy()));
            int dist = Math.max(Math.abs(r.dx()), Math.abs(r.dy()));  // Chebyshev
            return d == null ? null : new DirectionInfo(d, dist);
        }
        case Coord.Absolute ignored -> { return null; }
    }
}
```

SENSOR-derived cells (at distance >= 2) will have `dist >= 2` from the Chebyshev calculation. The priority cascade in `decideFullAuthority` uses `adjacent(nutrients, 1)` for step 4 (consume) and `adjacent(prey, 2)` for step 3 (chase). SENSOR-derived cells at `dist==2` participate in `closePrey` (step 3) and the nutrient movement step 6 (`!adjacent`, distance >= 2 nutrients). This is the correct emergent behaviour — the brain demonstrates steering toward food visible only via a SENSOR.

## Shared Patterns

### Per-tick inline derived projection (D-41 shape)

**Source:** `EnvironmentEngine.buildStatusCaches()` — `cellStatusCache` and `entityStatusCache` are rebuilt every tick at `@Order(14)`, then read by `TickBroadcaster` at `@Order(50)`.
**Apply to:** SENSOR union construction in `buildLocomotorCells` (TickBroadcaster).

Pattern: build the projection inline in the per-bot `buildTickFrame` call. No persistent cache. Stateless per invocation (pure function of current `worldGrid` + `compositeRegistry` state). This avoids the inter-run state leak (Pitfall 5 in RESEARCH.md).

### Toroidal relative-coord helper (`relativeTo`)

**Source:** `TickBroadcaster.relativeTo()` (lines 829–837)
**Apply to:** SENSOR union coordinate re-expression (locoPos-relative dx/dy for union cells) + ±63 clamp + warn pattern from `buildRosterIfChanged` (lines 876–879).

```java
// src/main/java/com/paralife/websocket/TickBroadcaster.java lines 829–837
private Position relativeTo(Position from, Position to) {
    int gridW = worldGrid.getWidth();
    int gridH = worldGrid.getHeight();
    int rawDx = Math.floorMod(to.x() - from.x(), gridW);
    int rawDy = Math.floorMod(to.y() - from.y(), gridH);
    int dx = rawDx <= gridW / 2 ? rawDx : rawDx - gridW;
    int dy = rawDy <= gridH / 2 ? rawDy : rawDy - gridH;
    return new Position(dx, dy);
}
```
