## Task-1 attemptPlacementForTest finding

`attemptPlacementForTest` (WorldWebSocketHandler.java lines 271–287) retries up to `LOST_RACE_MAX_RETRIES = 3` times (line 104, line 276). Each attempt samples an unoccupied position from `eligibleCellIndex.sample(spawnRng)` and calls `worldGrid.trySetEntity(...)`. If `trySetEntity` returns false (race — cell just became occupied), it increments the lost-race counter and retries. If all 3 attempts fail, it returns `Optional.empty()` and the test assertion at the call site fires.

**Consequence:** The 26-bot loop was left UNMODIFIED. `attemptPlacementForTest` naturally avoids the 2 composite-seeded cells. A manual `if(occupied) continue;` skip guard was NOT added (would silently drop a bot — 26→25 — and perturb the digest).
