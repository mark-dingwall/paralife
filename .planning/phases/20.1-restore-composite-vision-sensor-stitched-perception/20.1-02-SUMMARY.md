## What Was Built

**ActionResolver.nearestFreeCell (new private method):**
- Generates candidate offsets over `[-MAX_REPRODUCER_SEARCH_RADIUS, MAX_REPRODUCER_SEARCH_RADIUS]²` minus `(0,0)` **per call** (no static cache).
- Sorts by raw `dx*dx + dy*dy`, tie-break `dy`, then `dx` — plain `Comparator.comparingInt` chain.
- Iterates sorted offsets; for each applies `Math.floorMod` to compute the toroidal spawn target; returns the first cell that is not `claimedCells.contains()` and not `hasOccupant()`.
- Returns `null` if no free cell found within the radius.

**ActionResolver.resolveReproducerBud (modified):**
- Removed: `Direction dir = directionOf(rca.action)` and the `dir == null` early return.
- Removed: `dir.apply(...)` target derivation and the `claimedCells.contains` + `hasOccupant` guards (subsumed by `nearestFreeCell`).
- Added: `Position target = nearestFreeCell(rca.bot.position(), claimedCells); if (target == null) return;`
- Pool energy deduction stays **after** the `if (target == null) return` guard — bounded skip leaves pool untouched.
- Code comment documents: (a) bot still sends `a|R|<numpad>`, direction arg is server-ignored (TD for later contract cleanup); (b) sort key is raw because `maxRadius < dim/2`.

**MAX_REPRODUCER_SEARCH_RADIUS = 5 (package-visible static final):** scalar bound constant only, not an offset array.

**ReproducerAutoPlaceTest (new, 6 tests, all GREEN after Task 2):**
- `nearestFreePlacement_isDistanceOrdered_notFirstFound` — cells strictly closer than the expected bud cell are blocked; proves distance ordering, not first-found.
- `dualRun_determinism_sameSetupSameBudCell` — two independent resolver instances with identical setup produce the same bud cell.
- `tieBreak_lowerDyThenLowerDx_wins` — equidistant candidates; lower-dy then lower-dx wins.
- `edgeAdjacent_spawnWrap_deterministic` — REPRODUCER at (1,1) with some inner cells blocked; spawn wraps via `floorMod`; two identical runs produce the same bud cell. Does NOT claim raw vs wrapped sort differs (they are provably identical at this radius).
- `boundedSkip_noSpawn_poolEnergyUnchanged` — entire `[-5,5]²` neighbourhood blocked; no spawn, no exception, `compositeRegistry.getSharedEnergy()` before == after.
- `directionArgIgnored_placesAtNearestFree_notNoOp` — direction points at an occupied cell; bud still placed at nearest free.

**CompositeActionTest.reproducerBudsParticle (updated):**
- Changed assertion from `getCell(4,3)` (East of (3,3), the old direction-based target) to `getCell(3,2)` (nearest free by raw sort: offset (0,-1), d²=1, dy=-1, lowest in tie-break).
- Comment documents the auto-place semantics.
