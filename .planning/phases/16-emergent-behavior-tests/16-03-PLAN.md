import io.micrometer.core.instrument.DistributionSummary;
import io.micrometer.core.instrument.MeterRegistry;

private final DistributionSummary tickWork;

public TickEngine(TickConfig config, ApplicationEventPublisher eventPublisher,
                  MeterRegistry meterRegistry) {
    this.config = config;
    this.eventPublisher = eventPublisher;
    this.tickWork = DistributionSummary.builder("paralife.tick.work.ms")
            .description("Per-tick wall-clock work time end-to-end (listener dispatch + all @Order slots)")

**Step 2 — Modify tickLoop to record elapsed on the meter (PATTERNS.md lines 712-716):**

Existing body at lines 85-97 computes `elapsed` in ms. The load-bearing constraint: do not double-sample `System.nanoTime()` (PATTERNS.md line 719) — compute nanos once, derive both double-ms (for meter) and long-ms (for existing sleep-budget warn path):

```java
long tickNumber = tickCounter.incrementAndGet();
long startNs = System.nanoTime();

var event = new TickEvent(tickNumber);
eventPublisher.publishEvent(event);

long elapsedNs = System.nanoTime() - startNs;
tickWork.record(elapsedNs / 1_000_000.0);                                 // + new — double ms to meter
long elapsed = elapsedNs / 1_000_000;                                     // existing var preserved
long sleepTime = Math.max(0, config.intervalMs() - elapsed);
// existing warn-on-overrun path continues unchanged
```
