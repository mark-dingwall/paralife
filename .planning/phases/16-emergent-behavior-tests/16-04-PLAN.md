**Step 1b — Heap sampling on every sample() call (addresses BLOCKER 5 — heapGrowthPercent window math):**

Inside the body of `sample(...)`, unconditionally append the current heap bytes AND the current session count, mirroring the `history.add(...)` / `ticks.add(...)` writes — parallel lists, identical index:


`heapGrowthPercent(firstWindowStart, lastWindowStart, windowSize)` implementation:
1. Locate sample index for `firstWindowStart` via linear search of `ticks` (small N; O(N) fine).
2. Take up to `windowSize` samples starting at that index; compute `meanFirst = heapSamples.stream().skip(startIdx).limit(windowSize).mapToLong(Long::longValue).average().orElse(0.0)`.
3. Same for `lastWindowStart` → `meanLast`.
4. Return `(long) ((meanLast - meanFirst) * 100.0 / meanFirst)`. Guard against `meanFirst == 0`.

D-11 row 5 exact meaning: "last 200 ticks vs first 200 (post-warmup)". Consumer in 16-06 invokes `history.heapGrowthPercent(250L, 800L, 200)` — the first window spans samples in ticks [250..450], the last [800..1000].

**Step 1d — autocorrelation implementation (addresses BLOCKER 1 signal #4):**

Standard textbook lag-k autocorrelation on `typeSeries(type)`:

```java
public OptionalDouble autocorrelation(String type, int lag) {
    List<Integer> series = typeSeries(type);
    if (series.size() <= lag + 1) return OptionalDouble.empty();
    double mean = series.stream().mapToInt(Integer::intValue).average().orElse(0.0);
    double num = 0.0, den = 0.0;
    for (int t = 0; t < series.size() - lag; t++) {
        double a = series.get(t) - mean;
        double b = series.get(t + lag) - mean;
        num += a * b;
    }
    for (int t = 0; t < series.size(); t++) {
        double a = series.get(t) - mean;
        den += a * a;
    }
    return den == 0.0 ? OptionalDouble.of(0.0) : OptionalDouble.of(num / den);
}

public OptionalDouble maxAutocorrelation(int lag) {
    double best = Double.NEGATIVE_INFINITY;
    boolean any = false;
    for (String t : List.of("CATALYST", "MEMBRANE", "SPORE")) {
        OptionalDouble v = autocorrelation(t, lag);
        if (v.isPresent()) { best = Math.max(best, v.getAsDouble()); any = true; }
    }
    return any ? OptionalDouble.of(best) : OptionalDouble.empty();
}
```

```java
public class SeededBotLauncher {
    private static final Logger log = LoggerFactory.getLogger(SeededBotLauncher.class);
    private final List<BotClient> bots = new CopyOnWriteArrayList<>();

    public List<BotClient> launchSeeded(String serverUri, int count, long masterSeed) throws Exception {
        SplittableRandom master = new SplittableRandom(masterSeed);
        List<BotClient> launched = new CopyOnWriteArrayList<>();
        CountDownLatch allDone = new CountDownLatch(count);
        AtomicInteger registered = new AtomicInteger(0);
        ParticleType[] types = ParticleType.values();

        for (int i = 0; i < count; i++) {
            char species = switch (types[i % types.length]) {
                case CATALYST -> 'C';
                case MEMBRANE -> 'M';
                case SPORE -> 'S';
            };
            long botSeed = master.split().nextLong();
            BotClient bot = new BotClient(serverUri, species,
                    new HeuristicBrain(HeuristicBrain.REPRODUCE_THRESHOLD),
                    100L, 50L, new Random(botSeed));
            launched.add(bot);
            bots.add(bot);

            Thread.startVirtualThread(() -> {
                try {
                    bot.connect();
                    if (bot.waitForRegistered(10, TimeUnit.SECONDS)) {
                        registered.incrementAndGet();
                    }
                } catch (Exception e) {
                    log.warn("Seeded bot failed to connect: {}", e.getMessage());
                } finally {
                    allDone.countDown();
                }
            });
        }
        if (!allDone.await(30, TimeUnit.SECONDS)) {
            log.warn("Not all bots connected within 30s; registered={} of {}", registered.get(), count);
        }
        return new ArrayList<>(launched);
    }

    public void shutdown() {
        for (BotClient bot : bots) {
            try { bot.disconnect(); } catch (Exception ignored) {}
        }
        bots.clear();
    }

    public int botCount() { return bots.size(); }
}
```
