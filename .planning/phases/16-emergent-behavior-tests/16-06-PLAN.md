**Step 4 — Sampling loop — tick-count based, NOT Thread.sleep(N * interval) (PATTERNS.md line 279, RESEARCH Pitfall lines 329-333):**

```java
private void runSamplingLoop(PopulationHistory history,
                             TriggerWatcher starvationWatcher,
                             TriggerWatcher buffedWatcher,
                             int targetTicks,
                             long deadlineMs) throws Exception {
    long[] heapCheckpoints = {50L, 250L, 800L, 1000L};  // D-11 row 5
    int heapIdx = 0;
    while (history.tickCount() < targetTicks && System.currentTimeMillis() < deadlineMs) {
        Thread.sleep(15);
        long currentTick = tickEngine.getCurrentTick();
        history.sample(worldGrid, compositeRegistry, buffRegistry, botRegistry, currentTick);
        starvationWatcher.tickIfWindowActive(history, worldGrid);
        buffedWatcher.tickIfWindowActive(history, worldGrid);
        if (heapIdx < heapCheckpoints.length && history.tickCount() >= heapCheckpoints[heapIdx]) {
            history.sampleHeap();
            heapIdx++;
        }
    }
}
```
