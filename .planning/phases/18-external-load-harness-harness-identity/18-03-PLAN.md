    Step 1 — Create `src/main/java/com/paralife/admission/AttributionTagger.java`:

    The overflow-folding registry is a small piece of in-memory state owned by `AttributionTagger` (or injected from `AdmissionMetrics`). The contract: `tagsFor(session)` returns the SAME tags that the registry's MeterFilter would produce after applying `maximumAllowableTags`. By centralising the fold here, the bucket map keyed by `tagsFor(session)` cannot drift from the registry.

    ```java
    package com.paralife.admission;

    import com.paralife.bot.BotIdentity;
    import io.micrometer.core.instrument.Tags;
    import org.springframework.web.socket.WebSocketSession;

    import java.util.Set;
    import java.util.concurrent.ConcurrentHashMap;
    import java.util.concurrent.atomic.AtomicInteger;

    /**
     * Single source of truth for converting a {@link WebSocketSession} into the
     * Phase 18 D-11 two-tag attribution scheme:
     * <ul>
     *   <li>{@code source} ∈ {@link #SOURCE_TAXONOMY}; defaults to {@code "unknown"} when absent</li>
     *   <li>{@code harness} present only when {@code source=harness} (per D-11)</li>
     * </ul>
     *
     * <p><b>Overflow folding (Claude review amendment):</b> applied here, BEFORE returning Tags
     * to callers, so the in-memory bucket map (keyed by these Tags) and the registered Micrometer
     * Gauges (filtered by `MeterFilter.maximumAllowableTags`) always agree on the tag values.
     * Without this co-location, the 65th unique harness id would key a NEW bucket entry while
     * the registry registers a Gauge bound to the FIRST overflow bucket's AtomicInteger,
     * silently orphaning subsequent overflow buckets.
     */
    public final class AttributionTagger {

        public static final String ATTR_SOURCE  = "source";
        public static final String ATTR_HARNESS = "harness";
        public static final Set<String> SOURCE_TAXONOMY = BotIdentity.SOURCE_TAXONOMY;

        // Overflow-folding state — shared across tagsFor() invocations.
        // observedHarnessIds: insertion-ordered set up to maxCardinality entries.
        // Hosts a `register(harnessId)` semantic — first N are kept; N+1 returns "overflow".
        private final ConcurrentHashMap<String, Boolean> observedHarnessIds = new ConcurrentHashMap<>();
        private final AtomicInteger observedCount = new AtomicInteger();
        private final int maxCardinality;

        public AttributionTagger(int maxCardinality) {
            if (maxCardinality < 1) {
                throw new IllegalArgumentException("maxCardinality must be >= 1");
            }
            this.maxCardinality = maxCardinality;
        }

        /**
         * Build Micrometer tags for a session. Returns a singleton {@code source=unknown}
         * tag set when {@code session} is null. Applies overflow folding so callers and the
         * Micrometer registry observe identical tag values.
         */
        public Tags tagsFor(WebSocketSession session) {
            if (session == null) {
                return Tags.of("source", "unknown");
            }
            String source = sourceOf(session);
            String harness = harnessOf(session);
            if (harness == null) {
                return Tags.of("source", source);
            }
            String effective = foldHarnessIfOverCap(harness);
            return Tags.of("source", source, "harness", effective);
        }

        /**
         * Returns the harness id, or "overflow" when the cap is exceeded. Idempotent for
         * already-observed ids. Concurrency-safe via computeIfAbsent + atomic counter.
         */
        private String foldHarnessIfOverCap(String harnessId) {
            // Already observed → keep.
            if (observedHarnessIds.containsKey(harnessId)) {
                return harnessId;
            }
            // Try to claim a slot under the cap.
            // computeIfAbsent ensures atomic-once registration, but we still need to check the cap.
            Boolean prev = observedHarnessIds.putIfAbsent(harnessId, Boolean.TRUE);
            if (prev != null) {
                return harnessId;   // raced with another thread; the id is registered now.
            }
            int n = observedCount.incrementAndGet();
            if (n > maxCardinality) {
                // Roll back: we're past the cap. Remove our claim and fold to overflow.
                observedHarnessIds.remove(harnessId, Boolean.TRUE);
                observedCount.decrementAndGet();
                return "overflow";
            }
            return harnessId;
        }

        // Keep these as static utilities for the WorldWebSocketHandler/AdmissionGate log-format
        // path (no instance available there). Source classification doesn't need overflow folding.

        /** Returns the source attribute value or "unknown" if absent / unknown taxonomy. */
        public static String sourceOf(WebSocketSession session) {
            if (session == null) return "unknown";
            Object v = session.getAttributes().get(ATTR_SOURCE);
            if (v instanceof String s && SOURCE_TAXONOMY.contains(s)) return s;
            return "unknown";
        }

        /** Returns the harness id or null if absent. */
        public static String harnessOf(WebSocketSession session) {
            if (session == null) return null;
            Object v = session.getAttributes().get(ATTR_HARNESS);
            return v instanceof String s ? s : null;
        }

        /**
         * Formats source/harness as a space-delimited log-marker field suffix
         * (D-13 grep-friendly style, mirrors Phase 16 D-15). Static — no overflow folding
         * applied here (logs use raw harness ids; only metric tags fold).
         */
        public static String formatLogFields(WebSocketSession session) {
            String source = sourceOf(session);
            String harness = harnessOf(session);
            return harness == null
                    ? "source=" + source
                    : "source=" + source + " harness=" + harness;
        }
    }
    ```

Sites that need static log-formatting (`AdmissionGate.reject`, `WorldWebSocketHandler` BACKPRESSURE markers) call the static `formatLogFields(session)` directly — no overflow folding needed for log lines.
