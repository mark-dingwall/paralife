Build the standalone load-harness JVM (`com.paralife.harness.LoadHarness`) as a pure WS-client process — zero Spring context — driven by Picocli for the CLI surface (D-15, D-16), Jackson for the JSON / JSONL run report (D-17), and `BotFleet` (Plan 04) for the underlying VT-per-bot launching. Add the `loadHarnessJar` shaded BootJar task and `runHarness` JavaExec task to `build.gradle.kts`.

**Reviewer-driven amendments folded in:**
- **`--duration` is now `int durationSeconds`** (consensus, 3 of 4 reviewers): D-16 says `--duration=<seconds>`. Picocli 4.7 has no built-in `Duration` converter; ISO-8601 default `PT0S` was wrong. Use a sentinel `0` for "run forever".
- **`LoadHarness` itself is the `@Command` class implementing `Runnable`** (Codex amendment): Picocli's `CommandLine.execute(args)` only works on `@Command`-annotated `Runnable`/`Callable`. The previous shape (separate `LoadHarnessOptions` holder + manual `execute(args)` call) does not behave as expected. Move the `@Option` annotations onto `LoadHarness` directly OR keep `LoadHarnessOptions` as the field-bearing class but invoke via `CommandLine#parseArgs(...) + populateCommand(...)`. Choose the former — simpler, idiomatic Picocli.
- **Overwrite-mode report retains header fields** (OpenCode amendment): `computeSnapshot` previously called `ReportSnapshot.counters(...)` which nulled `harnessId`/`serverUri`/`targetCount`. Fix: store the initial header in `LoadHarness`, merge with live counters in every overwrite write so the on-disk JSON always carries static config alongside rolling counters.
- **`paralife.build.sha` decision (Codex/Claude LOW):** drop the field for now — no Gradle wiring this phase. Forward-noted in 18-HARNESS.md.
- **`BotFleet.shutdown()` idempotency (Claude LOW):** guard against double-call from shutdown hook + main `run()`. Use an `AtomicBoolean` or rely on `BotClient.disconnect()`'s existing `shutdown.set(true)` guard.
- **Wave-4 dry-run smoke task (cross-plan suggestion):** Plan 06 will assert `./gradlew loadHarnessJar && java -jar build/libs/*-load-harness.jar --help` exits 0 and prints the flag list — Pitfall 5 lock.

Purpose: Closes SCALE-03. Operators get a real >100-bot harness; per-harness identity flows naturally through the existing Plan 01–04 infrastructure.
Output: A `java -jar build/libs/paralife-load-harness.jar --server-uri ws://... --count 200 --duration 600` invocation that connects 200 bots, writes a periodic JSON report, and exits cleanly on SIGINT/SIGTERM.

    import com.paralife.bot.RampUpSpec;
    import picocli.CommandLine.ITypeConverter;

    public final class RampUpConverter implements ITypeConverter<RampUpSpec> {
        @Override
        public RampUpSpec convert(String value) {
            if ("instant".equals(value)) return RampUpSpec.instant();
            if (value.startsWith("rate:")) {
                int n = Integer.parseInt(value.substring(5));
                return RampUpSpec.rate(n);
            }
            if (value.startsWith("wave:")) {
                String[] parts = value.substring(5).split(":");
                if (parts.length != 2) {
                    throw new IllegalArgumentException("--ramp-up wave format: wave:<count>:<sleepMs>");
                }
                return RampUpSpec.wave(Integer.parseInt(parts[0]), Long.parseLong(parts[1]));
            }
            throw new IllegalArgumentException("--ramp-up must be 'instant' | 'rate:<n>' | 'wave:<count>:<sleepMs>'; got: " + value);
        }
    }

    import com.fasterxml.jackson.annotation.JsonInclude;
    import com.fasterxml.jackson.annotation.JsonInclude.Include;

    @JsonInclude(Include.NON_NULL)
    public record ReportSnapshot(
            // Static config (header line in JSONL append mode)
            String harnessId,
            String serverUri,
            Integer targetCount,
            String startWallTime,
            String jvmVersion,
            // Rolling counters (every line in JSONL; current state in overwrite)
            Integer peakRegistered,
            Integer currentRegistered,
            Long connectFailuresTotal,
            Long e408ReconnectRequiredTotal,
            Long respawnsTotal,
            Long actionsSentTotal,
            Long perceptionsReceivedTotal,
            Long syncsReceivedTotal,
            Long wallTimeSecondsElapsed,
            String exitReason   // populated only on final write
    ) {
        public static ReportSnapshot header(String harnessId, String serverUri, int targetCount,
                                             String startWallTime, String jvmVersion) {
            return new ReportSnapshot(harnessId, serverUri, targetCount, startWallTime, jvmVersion,
                    null, null, null, null, null, null, null, null, null, null);
        }
        public static ReportSnapshot counters(Integer peakRegistered, Integer currentRegistered,
                                                Long connectFailures, Long e408, Long respawns,
                                                Long actions, Long perceptions, Long syncs,
                                                Long wallSecs, String exitReason) {
            return new ReportSnapshot(null, null, null, null, null,
                    peakRegistered, currentRegistered, connectFailures, e408,
                    respawns, actions, perceptions, syncs, wallSecs, exitReason);
        }
        /**
         * OpenCode review amendment — overwrite-mode merge. Returns a snapshot with header fields
         * from `header` and counter fields from `counters`. Used by {@code LoadHarness.computeSnapshot}

                    header.startWallTime, header.jvmVersion,

                    counters.connectFailuresTotal, counters.e408ReconnectRequiredTotal,
                    counters.respawnsTotal, counters.actionsSentTotal,
                    counters.perceptionsReceivedTotal, counters.syncsReceivedTotal,
                    counters.wallTimeSecondsElapsed, counters.exitReason);
        }
    }

    ```java
    package com.paralife.harness;

    import com.fasterxml.jackson.databind.ObjectMapper;
    import org.slf4j.Logger;
    import org.slf4j.LoggerFactory;

    import java.io.IOException;
    import java.io.OutputStream;
    import java.nio.charset.StandardCharsets;
    import java.nio.file.AtomicMoveNotSupportedException;
    import java.nio.file.Files;
    import java.nio.file.Path;
    import java.nio.file.StandardCopyOption;
    import java.nio.file.StandardOpenOption;
    import java.util.concurrent.atomic.AtomicBoolean;

    public final class ReportWriter {

        private static final Logger log = LoggerFactory.getLogger(ReportWriter.class);
        private final ObjectMapper mapper = new ObjectMapper();
        private final AtomicBoolean headerWritten = new AtomicBoolean(false);

        public void writeOverwrite(Path target, ReportSnapshot snapshot) throws IOException {
            Path dir = target.toAbsolutePath().getParent();
            if (dir != null) Files.createDirectories(dir);
            Path tmp = (dir == null ? Path.of(".") : dir).resolve(target.getFileName() + ".tmp");
            try (OutputStream out = Files.newOutputStream(tmp,
                    StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE)) {
                mapper.writeValue(out, snapshot);
            }
            atomicReplace(tmp, target);
        }

        public void writeJsonlHeader(Path target, ReportSnapshot header) throws IOException {
            Path dir = target.toAbsolutePath().getParent();
            if (dir != null) Files.createDirectories(dir);
            Path tmp = (dir == null ? Path.of(".") : dir).resolve(target.getFileName() + ".tmp");
            String line = mapper.writeValueAsString(header) + "\n";
            Files.writeString(tmp, line, StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
            atomicReplace(tmp, target);
            headerWritten.set(true);
        }

        public void appendJsonlCounter(Path target, ReportSnapshot counter) throws IOException {
            if (!headerWritten.get()) {
                throw new IllegalStateException("appendJsonlCounter called before writeJsonlHeader");
            }
            String line = mapper.writeValueAsString(counter) + "\n";
            Files.writeString(target, line, StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE, StandardOpenOption.WRITE,
                    StandardOpenOption.APPEND, StandardOpenOption.SYNC);
        }

        private void atomicReplace(Path tmp, Path target) throws IOException {
            try {
                Files.move(tmp, target, StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING);
            } catch (AtomicMoveNotSupportedException e) {
                log.warn("Atomic move unsupported on this filesystem ({}); falling back to non-atomic", e.getMessage());
                Files.move(tmp, target, StandardCopyOption.REPLACE_EXISTING);
            }
        }
    }
    ```

    package com.paralife.harness;

    import com.paralife.bot.BotClient;
    import com.paralife.bot.BotFactory;
    import com.paralife.bot.BotFleet;
    import com.paralife.bot.BotIdentity;
    import com.paralife.bot.RampUpSpec;
    import com.paralife.bot.SpeciesMix;
    import org.slf4j.Logger;
    import org.slf4j.LoggerFactory;
    import picocli.CommandLine;
    import picocli.CommandLine.Command;
    import picocli.CommandLine.Option;

    import java.nio.file.Path;
    import java.time.Duration;
    import java.time.Instant;
    import java.util.concurrent.CountDownLatch;
    import java.util.concurrent.TimeUnit;
    import java.util.concurrent.atomic.AtomicReference;

    /**
     * Standalone external load harness (Phase 18 D-15).
     *
     * <p>Pure {@code public static void main} — NO Spring context (RESEARCH.md Pitfall 5).
     * Per Codex review amendment, this class is itself the {@code @Command} implementing
     * {@link Runnable}; Picocli wires fields directly.
     */
    @Command(name = "load-harness", mixinStandardHelpOptions = true,
            description = "Paralife external load harness (Phase 18 D-15).")
    public final class LoadHarness implements Runnable {

        private static final Logger log = LoggerFactory.getLogger(LoadHarness.class);

        @Option(names = "--server-uri", required = true,
                defaultValue = "${PARALIFE_HARNESS_SERVER_URI}",
                description = "WebSocket server URI (e.g. ws://localhost:8080/ws/world).")
        String serverUri;

        @Option(names = "--count", required = true,
                defaultValue = "${PARALIFE_HARNESS_COUNT}",
                description = "Number of bots to launch.")
        int count;

        @Option(names = "--harness-id",
                defaultValue = "${PARALIFE_HARNESS_HARNESS_ID}",
                description = "Harness identity (auto-generated if absent).")
        String harnessId;

        @Option(names = "--ramp-up",
                defaultValue = "${PARALIFE_HARNESS_RAMP_UP:-rate:50}",
                converter = RampUpConverter.class,
                description = "instant | rate:<n> | wave:<count>:<sleepMs>. Default rate:50.")
        RampUpSpec rampUp;

        @Option(names = "--species-mix",
                defaultValue = "${PARALIFE_HARNESS_SPECIES_MIX:-balanced}",
                converter = SpeciesMixConverter.class,
                description = "balanced | <C>:<M>:<S>. Default balanced.")
        SpeciesMix speciesMix;

        // Phase 18 D-16 / consensus amendment: --duration is INTEGER seconds.
        // 0 = run indefinitely (until SIGINT/SIGTERM).
        @Option(names = "--duration",
                defaultValue = "${PARALIFE_HARNESS_DURATION:-0}",
                description = "Run duration in seconds (0 = indefinite). Default 0.")
        int durationSeconds;

        @Option(names = "--report-out",
                defaultValue = "${PARALIFE_HARNESS_REPORT_OUT}",
                description = "Report output path. Default ./harness-<id>-report.json.")
        Path reportOut;

        @Option(names = "--report-mode",
                defaultValue = "${PARALIFE_HARNESS_REPORT_MODE:-overwrite}",
                description = "overwrite | append. Default overwrite.")
        String reportMode;

        @Option(names = "--report-interval",
                defaultValue = "${PARALIFE_HARNESS_REPORT_INTERVAL:-30}",
                description = "Report write interval in seconds. Range 10..300. Default 30.")
        int reportIntervalSeconds;

        // Initial header — set ONCE in run() before the periodic reporter VT starts.
        // OpenCode amendment: every overwrite write merges this with live counters so
        // the on-disk JSON never loses harnessId/serverUri/targetCount.
        private ReportSnapshot initialHeader;

        public static void main(String[] args) {
            int rc = new CommandLine(new LoadHarness()).execute(args);
            System.exit(rc);
        }

        @Override
        public void run() {
            validateAndDefault();
            int rc = runInternal();
            // Picocli's Runnable contract: void return — translate non-zero into exit elsewhere.
            // Use ExitCode-aware variant: setting an exit code via CommandLine.IExitCodeGenerator
            // OR just call System.exit(rc) here for simplicity. Choose the latter for deterministic
            // shutdown of the harness process.
            if (rc != 0) {
                System.exit(rc);
            }
        }

        void validateAndDefault() {
            if (count < 1) throw new IllegalArgumentException("--count must be >= 1");
            if (reportIntervalSeconds < 10 || reportIntervalSeconds > 300) {
                throw new IllegalArgumentException("--report-interval must be 10..300 (got " + reportIntervalSeconds + ")");
            }
            if (!"overwrite".equals(reportMode) && !"append".equals(reportMode)) {
                throw new IllegalArgumentException("--report-mode must be overwrite|append (got " + reportMode + ")");
            }
            if (durationSeconds < 0) {
                throw new IllegalArgumentException("--duration must be >= 0 (got " + durationSeconds + ")");
            }
            if (harnessId == null || harnessId.isBlank()) {
                harnessId = generateHarnessId();
            }
            if (reportOut == null) {
                reportOut = Path.of("./harness-" + harnessId + "-report.json");
            }
        }

        private static String generateHarnessId() {
            String hex = Long.toHexString(java.util.concurrent.ThreadLocalRandom.current().nextLong());
            String full = "harness-" + hex;
            return full.substring(0, Math.min(32, full.length()));
        }

        int runInternal() {
            log.info("LoadHarness starting — harness-id={} server={} count={} duration={}s ramp-up={}",
                    harnessId, serverUri, count,
                    durationSeconds == 0 ? "indefinite" : Integer.toString(durationSeconds),
                    rampUp);

            BotFleet fleet = new BotFleet();
            BotFactory factory = new BotFactory(serverUri);
            BotIdentity identity = BotIdentity.harness(harnessId);
            ReportWriter writer = new ReportWriter();
            Instant startedAt = Instant.now();
            AtomicReference<String> exitReason = new AtomicReference<>(null);
            CountDownLatch exitLatch = new CountDownLatch(1);

            // OpenCode amendment: store the initial header so every overwrite write merges
            // it with live counters — header fields never lost.
            initialHeader = ReportSnapshot.header(harnessId, serverUri, count,
                    startedAt.toString(), System.getProperty("java.version"));
            try {
                if ("append".equals(reportMode)) {
                    writer.writeJsonlHeader(reportOut, initialHeader);
                } else {
                    writer.writeOverwrite(reportOut, initialHeader);
                }
            } catch (Exception e) {
                log.error("Initial report write failed: {}", e.getMessage());
                return 2;
            }

            // Periodic counter writer VT.
            Thread reporterVT = Thread.ofVirtual().start(() -> {
                while (exitReason.get() == null) {
                    try {
                        Thread.sleep(reportIntervalSeconds * 1000L);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                    if (exitReason.get() != null) return;
                    try {
                        writeCounters(writer, fleet, startedAt, null);
                    } catch (Exception e) {
                        log.warn("Periodic report write failed: {}", e.getMessage());
                    }
                }
            });

            // Shutdown hook for SIGINT/SIGTERM. Plan 04 BotFleet.shutdown is now idempotent
            // (Codex/Claude amendment) so this safely runs alongside the main run() shutdown.
            Runtime.getRuntime().addShutdownHook(new Thread(() -> {
                exitReason.compareAndSet(null, "signal-term");
                fleet.shutdown();
                exitLatch.countDown();
            }, "load-harness-shutdown"));

            // Launch the fleet.
            try {
                fleet.launch(serverUri, count, identity, rampUp, speciesMix, factory);
            } catch (Exception e) {
                log.error("Fleet launch failed: {}", e.getMessage(), e);
                exitReason.set("fatal-error");
                writeFinalAndReturn(writer, fleet, startedAt, exitReason.get());
                return 2;
            }

            // Run for duration, indefinitely, or until SIGINT.
            if (durationSeconds > 0) {
                try {
                    if (exitLatch.await(durationSeconds, TimeUnit.SECONDS)) {
                        // signaled
                    } else {
                        exitReason.compareAndSet(null, "duration-reached");
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    exitReason.compareAndSet(null, "signal-int");
                }
            } else {
                try { exitLatch.await(); } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    exitReason.compareAndSet(null, "signal-int");
                }
            }

            // Final write.
            String reason = exitReason.get() == null ? "duration-reached" : exitReason.get();
            writeFinalAndReturn(writer, fleet, startedAt, reason);
            fleet.shutdown();   // idempotent — safe to call again here even if shutdown hook fired
            return 0;
        }

        private void writeCounters(ReportWriter w, BotFleet fleet,
                                    Instant startedAt, String exitReason) throws java.io.IOException {
            ReportSnapshot counters = computeCountersSnapshot(fleet, startedAt, exitReason);
            if ("append".equals(reportMode)) {
                // Append-mode: counter-only line (header was the first JSONL line).
                w.appendJsonlCounter(reportOut, counters);
            } else {
                // Overwrite-mode (OpenCode amendment): MERGE header + counters so on-disk
                // JSON always carries both static config and live counters.
                w.writeOverwrite(reportOut, ReportSnapshot.merge(initialHeader, counters));
            }
        }

        private void writeFinalAndReturn(ReportWriter w, BotFleet fleet,
                                          Instant startedAt, String exitReason) {
            try {
                writeCounters(w, fleet, startedAt, exitReason);
            } catch (Exception e) {
                log.warn("Final report write failed: {}", e.getMessage());
            }
        }

        private ReportSnapshot computeCountersSnapshot(BotFleet fleet,
                                                Instant startedAt, String exitReason) {
            long actions = 0, perceptions = 0, syncs = 0, respawns = 0, e408 = 0, failures = 0;
            for (BotClient b : fleet.getBots()) {
                actions     += b.getActionCount();
                perceptions += b.getPerceptionCount();
                respawns    += b.getRespawnCount();
                e408        += b.getE408ReconnectRequiredCount();
                if (b.isRegistered()) syncs += 1L + b.getRespawnCount();
                if (!b.isRegistered() && !b.isConnected()) failures += 1;
            }
            long elapsedSec = Duration.between(startedAt, Instant.now()).toSeconds();
            return ReportSnapshot.counters(
                    fleet.peakRegistered(), fleet.currentRegistered(),
                    failures, e408, respawns,
                    actions, perceptions, syncs,
                    elapsedSec,
                    exitReason);
        }
    }
