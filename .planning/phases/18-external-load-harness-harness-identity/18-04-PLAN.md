    Step 3 — Create `src/main/java/com/paralife/bot/BotFleet.java`:

    **Peak-tracking contract (locked):** `peakRegistered` is a true high-water mark — it must equal `max(currentRegistered) over JVM lifetime` and never decrease. Implementation: TWO atomic counters — `liveCount` (live registered bots, inc on register-success, dec on disconnect) and `highWater` (snapshot of the largest `liveCount` ever observed). On register-success: `int live = liveCount.incrementAndGet(); highWater.updateAndGet(prev -> Math.max(prev, live));`. On disconnect: `liveCount.decrementAndGet();` (highWater never decremented). The previously-considered shape `int peak = peakRegistered.incrementAndGet(); if (peak > peakRegistered.get()) peakRegistered.set(peak);` is broken (the conditional always reads its own freshly-incremented value AND there's no decrement on disconnect, so it tracks cumulative registrations not a high-water mark) — DO NOT use it.

    **`currentRegistered()` semantics (OpenCode amendment — must be documented in Javadoc):** `liveCount` is incremented inside the launch VT when `awaitRegistered` succeeds, decremented via `bot.onClose(...)`. When a `BotClient` reconnects after a STALLED-pivot (Phase 17 D-13), it does so through its own internal loop, NOT through `BotFleet`. So after a STALLED pivot the `onClose` callback fires once (decrementing liveCount), but the post-reconnect register-success is invisible to the fleet — there is no re-increment. `currentRegistered()` is therefore best-effort for the ramp window only; long-running harnesses must use the server-side gauge `paralife.admission.active.entities{source=harness, harness=...}` (Plan 03) or per-bot `BotClient.isRegistered()` polling for accurate steady-state counts.

    ```java
    package com.paralife.bot;

    import com.paralife.world.Entity.ParticleType;
    import org.slf4j.Logger;
    import org.slf4j.LoggerFactory;

    import java.util.List;
    import java.util.Map;
    import java.util.Optional;
    import java.util.concurrent.CompletableFuture;
    import java.util.concurrent.ConcurrentHashMap;
    import java.util.concurrent.CopyOnWriteArrayList;
    import java.util.concurrent.TimeUnit;
    import java.util.concurrent.atomic.AtomicInteger;

    /**
     * Async VT-per-bot launcher (Phase 18 D-04).
     *
     * <p>Replaces {@link BotLauncher}'s 30s {@code allDone.await(30, TimeUnit.SECONDS)} ceiling
     * with per-bot {@code CompletableFuture<RegistrationResult>} tracking. Callers (BotRunner,
     * LoadHarness) choose their own observability strategy via {@link #peakRegistered},
     * {@link #currentRegistered}, {@link #awaitAllSettled}.
     *
     * <p><b>Peak-tracking contract.</b> {@link #peakRegistered()} is a TRUE high-water mark:
     * monotonic-non-decreasing for the lifetime of this BotFleet instance, and equal to the
     * largest value of {@link #currentRegistered()} ever observed. Implemented via paired
     * atomics: {@code liveCount} (inc on register-success, dec on disconnect) and
     * {@code highWater} (max-folded against {@code liveCount} on each register-success).
     *
     * <p><b>Ramp-up scheduling.</b> The launcher loop blocks per-bot on {@link RampUpSpec},
     * NOT on the per-bot connect VT. {@code RampUpSpec.instant()} is a no-op block — fires all
     * VTs in a tight loop (matches today's BotLauncher). {@code RampUpSpec.rate(50)} sleeps
     * 20ms between bots. {@code RampUpSpec.wave(count, sleepMs)} bursts then sleeps.
     */
    public final class BotFleet {

        private static final Logger log = LoggerFactory.getLogger(BotFleet.class);

        public record RegistrationResult(String botId, boolean registered, Optional<String> failureReason) {}

        private final List<BotClient> bots = new CopyOnWriteArrayList<>();
        private final Map<String, CompletableFuture<RegistrationResult>> futures = new ConcurrentHashMap<>();
        // Peak-tracking: liveCount = currently-registered, highWater = max liveCount ever seen.
        private final AtomicInteger liveCount = new AtomicInteger();
        private final AtomicInteger highWater = new AtomicInteger();

        public List<BotClient> launch(String serverUri, int count, BotIdentity identity,
                                       RampUpSpec rampUp, SpeciesMix mix, BotFactory factory) {
            ParticleType[] types = ParticleType.values();
            for (int i = 0; i < count; i++) {
                rampUp.awaitNext(i);   // blocks the launcher thread per-bot per RampUpSpec contract
                char species = mix.pickFor(i, count, types);
                BotClient bot = factory.create(species, identity, Optional.empty(), Optional.empty());
                // Bind disconnect callback so liveCount tracks live bots, not cumulative.
                bot.onClose(() -> liveCount.decrementAndGet());
                bots.add(bot);
                String botId = "fleet-" + identity.harnessId().orElse("op") + "-" + i;
                CompletableFuture<RegistrationResult> fut = new CompletableFuture<>();
                futures.put(botId, fut);
                Thread.startVirtualThread(() -> {
                    try {
                        bot.connect();
                        boolean ok = bot.awaitRegistered(15_000L);
                        if (ok) {
                            int live = liveCount.incrementAndGet();
                            // Fold live into the high-water mark — true monotonic max.
                            highWater.updateAndGet(prev -> Math.max(prev, live));
                        }
                        fut.complete(new RegistrationResult(botId, ok, Optional.empty()));
                    } catch (Exception e) {
                        log.warn("Bot {} failed to connect: {}", botId, e.getMessage());
                        fut.complete(new RegistrationResult(botId, false, Optional.of(e.getMessage())));
                    }
                });
            }
            return List.copyOf(bots);
        }

        /** True high-water mark: never decreases. */
        public int peakRegistered() {
            return highWater.get();
        }

        /**
         * Live registered count. Decreases on {@link BotClient#onClose} firing.
         *
         * <p><b>Best-effort for the ramp window only (OpenCode review amendment).</b> A
         * {@code BotClient} that re-registers after a STALLED pivot (Phase 17 D-13) does so
         * through its own internal reconnect loop, NOT through this fleet, so the post-reconnect
         * register-success is invisible to {@code liveCount}. After any STALLED pivot, the
         * value returned here may undercount the true number of live registrations.
         *
         * <p>Authoritative steady-state sources:
         * <ul>
         *   <li><b>Server-side</b> (Plan 03): {@code paralife.admission.active.entities{source=harness, harness=<id>}} gauge</li>
         *   <li><b>Client-side</b>: poll {@link BotClient#isRegistered()} across {@link #getBots()} (used by {@code LoadHarness.computeSnapshot})</li>
         * </ul>
         */
        public int currentRegistered() {
            return liveCount.get();
        }

        public CompletableFuture<Void> awaitAllSettled() {
            return CompletableFuture.allOf(futures.values().toArray(CompletableFuture[]::new));
        }

        public List<BotClient> getBots() {
            return List.copyOf(bots);
        }

        public void shutdown() {
            for (BotClient b : bots) b.disconnect();
            log.info("BotFleet: {} bots disconnected", bots.size());
            bots.clear();
            futures.clear();
            // liveCount will drift to 0 via the onClose callbacks fired from disconnect();
            // do NOT reset highWater — it represents the JVM-lifetime peak.
        }
    }
    ```

    ```java
    // RampUpSpec.java — sealed interface with three impls
    public sealed interface RampUpSpec permits RampUpSpec.Instant, RampUpSpec.Rate, RampUpSpec.Wave {
        void awaitNext(int botIndex);
        record Instant() implements RampUpSpec {
            public void awaitNext(int botIndex) { /* no-op */ }
        }
        record Rate(int perSecond) implements RampUpSpec {
            public Rate { if (perSecond < 1) throw new IllegalArgumentException("perSecond >= 1"); }
            public void awaitNext(int botIndex) {
                if (botIndex == 0) return;
                long sleepMs = 1000L / perSecond;
                try { Thread.sleep(sleepMs); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            }
        }
        record Wave(int count, long sleepMs) implements RampUpSpec {
            public Wave { if (count < 1 || sleepMs < 0) throw new IllegalArgumentException(); }
            public void awaitNext(int botIndex) {
                if (botIndex == 0) return;
                if (botIndex % count == 0) {
                    try { Thread.sleep(sleepMs); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
                }
            }
        }
        static RampUpSpec instant() { return new Instant(); }
        static RampUpSpec rate(int perSecond) { return new Rate(perSecond); }
        static RampUpSpec wave(int count, long sleepMs) { return new Wave(count, sleepMs); }
    }
    ```

    ```java
    // SpeciesMix.java — balanced or weighted distribution
    public record SpeciesMix(double cFrac, double mFrac, double sFrac) {
        public SpeciesMix {
            double sum = cFrac + mFrac + sFrac;
            if (Math.abs(sum - 1.0) > 0.001) {
                throw new IllegalArgumentException("fractions must sum to 1.0 (got " + sum + ")");
            }
        }
        public static SpeciesMix balanced() { return new SpeciesMix(1.0/3, 1.0/3, 1.0/3); }
        public char pickFor(int i, int count, com.paralife.world.Entity.ParticleType[] types) {
            // For balanced: round-robin C/M/S to match today's BotLauncher behaviour.
            if (Math.abs(cFrac - 1.0/3) < 0.001 && Math.abs(mFrac - 1.0/3) < 0.001) {
                return switch (types[i % types.length]) {
                    case CATALYST -> 'C';
                    case MEMBRANE -> 'M';
                    case SPORE    -> 'S';
                };
            }
            // For weighted: deterministic position-based partitioning.
            double frac = (i + 0.5) / count;   // bot's position in [0,1)
            if (frac < cFrac) return 'C';
            if (frac < cFrac + mFrac) return 'M';
            return 'S';
        }
    }
    ```
