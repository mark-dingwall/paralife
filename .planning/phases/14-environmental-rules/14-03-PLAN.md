## Revision Notes (reviews cycle)

This revision addresses Codex HIGH 4 (buff grant ordering unsafe around lethal hits), Codex MEDIUM (BondedPair mutagen semantics unspecified, outbreak lifetime implicit, flaky wall-clock perf assertion), and Codex HIGH 3 (attack-path coverage for the D-20 attack-cure-reduction mechanic).

**Core changes:**
- Codex HIGH 4: introduces a `pendingBuffGrants` queue inside `tickBuffsAndInfections`. Cure events (via DoT expiry or `reduceInfection`) enqueue a grant; a second post-damage pass evaluates each pending grant AFTER all this-tick damage, discarding grants whose target `!isAlive()` or whose cell is now empty.
- Codex MEDIUM: BondedPair mutagen is treated as ONE shared infection keyed by `bp.id()` — not per-member. One survivor buff goes to `bp.id()` on cure. Rationale annotated in CONTEXT.md Deferred Ideas (developer confirmation at execute time).
- Codex MEDIUM: outbreak lifetime is a named config field `config.mutagen().outbreakLifetimeTicks` (default 300). No longer implicit `infectionDurationMax * 10`.
- Codex MEDIUM: perf test replaces wall-clock `< 50ms` with a structural assertion — instrument `tickBuffsAndInfections` to count grid reads; assert `gridReadCount ≤ W * H + infections.size()` (single pass).
- Codex HIGH 3: enumerate the attack-cure-reduction call sites across all 5 in-sim attack branches AND the ActionResolver site — mirror the splash-damage enumeration from Plan 02.

```java
void resolveMutagenCollisions(long tick) {
    var cfg = config.mutagen();
    int w = worldGrid.getWidth(), h = worldGrid.getHeight();
    for (int x = 0; x < w; x++) {
        for (int y = 0; y < h; y++) {
            int strain = mutagenGrid[x][y] & 0xFF;
            if (strain == 0) continue;
            Cell cell = worldGrid.getCell(x, y);
            if (cell.isEmpty()) continue;
            String entityId = entityIdOf(cell.occupant());
            if (entityId == null) continue;
            // Codex MEDIUM: BondedPair is ONE infection keyed by bp.id(), not per-member.
            if (infections.containsKey(entityId)) continue;
            Long immuneUntil = cureImmuneUntil.get(entityId);
            if (immuneUntil != null && immuneUntil >= tick) continue;

            int duration = cfg.infectionDurationMin()
                    + rng.nextInt(cfg.infectionDurationMax() - cfg.infectionDurationMin() + 1);
            infections.put(entityId, new Infection(
                    duration, duration, (byte) strain, cfg.damagePerTick(), new Position(x, y)));
        }
    }
}

private String entityIdOf(Entity e) {
    return switch (e) {

        case Entity.BondedPair bp -> bp.id();       // Codex MEDIUM: shared BondedPair id
        case Entity.CompositeMember cm -> cm.id();
        default -> null;
    };
}
```

```java
void tickBuffsAndInfections(long tick) {
    var cfg = config.mutagen();
    if (!infections.isEmpty()) {
        // SINGLE per-tick grid pass (HIGH 2)
        Map<String, int[]> infectedPositions = new HashMap<>();
        Map<String, Entity> infectedOccupants = new HashMap<>();
        int w = worldGrid.getWidth(), h = worldGrid.getHeight();
        for (int x = 0; x < w; x++) {
            for (int y = 0; y < h; y++) {
                gridReadCountForTest++;       // Codex MEDIUM: structural perf counter
                Cell c = worldGrid.getCell(x, y);
                if (c.isEmpty()) continue;
                String id = entityIdOf(c.occupant());
                if (id == null) continue;
                if (!infections.containsKey(id)) continue;
                infectedPositions.put(id, new int[]{x, y});
                infectedOccupants.put(id, c.occupant());
            }
        }

        // Phase A: apply DoT damage + decrement; enqueue cures as pending grants (no immediate grant).
        boolean anyDamage = false;
        for (var entry : new HashMap<>(infections).entrySet()) {
            String id = entry.getKey();
            Infection inf = entry.getValue();
            int[] pos = infectedPositions.get(id);
            Entity occ = infectedOccupants.get(id);
            if (pos != null && occ != null) {
                int damage = inf.damagePerTick();
                int x = pos[0], y = pos[1];
                switch (occ) {
                    case Entity.Particle p ->
                            worldGrid.setEntity(x, y, p.withEnergy(Math.max(0, p.energy() - damage)));
                    case Entity.BondedPair bp ->
                            worldGrid.setEntity(x, y, bp.withEnergy(Math.max(0, bp.energy() - damage)));
                    case Entity.CompositeMember cm ->
                            worldGrid.setEntity(x, y, cm.withEnergy(Math.max(0, cm.energy() - damage)));
                    default -> { /* ignore */ }
                }
                anyDamage = true;
                inf = inf.withPosition(new Position(x, y));
            }
            Infection next = inf.decrement();
            if (next.isExpired()) {
                // Codex HIGH 4: do NOT grant immediately — enqueue for post-damage alive-check.
                pendingBuffGrants.add(new PendingGrant(id, inf.initialTicks(), occ));
                infections.remove(id);
            } else {
                infections.put(id, next);
            }
        }
        if (anyDamage) markEnvDamageApplied();

        // Phase B (Codex HIGH 4): evaluate pending grants AFTER damage is applied.
        // An entity that was cured by DoT expiry AND took lethal damage in the same tick
        // has been updated on the grid via withEnergy(0) already — isAliveEntity check filters it out.
        for (PendingGrant pg : pendingBuffGrants) {
            int[] pos = infectedPositions.get(pg.entityId());
            if (pos == null) continue;  // entity already moved/cleared this tick — skip
            Cell postCell = worldGrid.getCell(pos[0], pos[1]);
            if (postCell.isEmpty()) continue;
            Entity postOcc = postCell.occupant();
            if (!isAliveEntity(postOcc)) continue;  // Codex HIGH 4: dead after damage — no buff
            if (!pg.entityId().equals(entityIdOf(postOcc))) continue;  // occupant changed
            grantSurvivorBuffs(pg.entityId(), tick, cfg, pg.initialTicks(), postOcc);
            cureImmuneUntil.put(pg.entityId(), tick + cfg.cureTicks());
        }
        pendingBuffGrants.clear();
    }

    cureImmuneUntil.entrySet().removeIf(ent -> ent.getValue() < tick);
```
