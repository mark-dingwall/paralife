## Revision Notes (reviews cycle 3)

This revision addresses the cycle-3 Codex feedback on 14-03: one real cure-path bug, one perf regression, and the documentation / coverage items from cycle 2.

**Core changes from cycle 2 plan:**

1. **Cure-path bug fix (Codex MEDIUM/HIGH cycle 3):** `PendingGrant` now carries its own `Position` field. The post-damage buff-grant pass (Phase B in `tickBuffsAndInfections`) looks up the occupant at `pg.position()` DIRECTLY — it does NOT re-index `infections` by id. This closes the silent drop where a target cured by `reduceInfection` earlier in the tick (and therefore removed from the `infections` map) would have no position lookup and its pending grant would be discarded. Grants now survive mid-tick map eviction.

2. **`reduceInfection` perf fix (Codex MEDIUM cycle 3):** signature changes from `reduceInfection(String id, int ticks, long currentTick)` to `reduceInfection(String id, int ticks, long currentTick, Position position)`. All callers (`SimulationEngine.processInteractions` 5 sites, `ActionResolver.resolveCompositeAttack` 1 site) already have the defender position in scope (`nPos` or `targetPos`), so they pass it directly. `findOccupantById()` is removed from the hot path. `reduceInfection` itself enqueues a PendingGrant using the passed Position and the occupant currently at that cell (or skips enqueue if the cell has been vacated mid-tick).

3. **No change to other cycle-2 fixes:** Codex HIGH 4 post-damage alive-gate, Codex MEDIUM BondedPair shared-infection semantics, Codex MEDIUM structural perf counter, Codex MEDIUM named outbreakLifetimeTicks — all preserved.

void resolveMutagenCollisions(long tick) {
    var cfg = config.mutagen();
    int w = worldGrid.getWidth(), h = worldGrid.getHeight();
    for (int x = 0; x < w; x++) {
        for (int y = 0; y < h; y++) {
            int strain = mutagenGrid[x][y] & 0xFF;
            if (strain == 0) continue;
            Cell cell = worldGrid.getCell(x, y);
            if (cell.isEmpty()) continue;

            infections.put(entityId, new Infection(
                    duration, duration, (byte) strain, cfg.damagePerTick(), new Position(x, y)));

}

void tickBuffsAndInfections(long tick) {
    var cfg = config.mutagen();
    if (!infections.isEmpty() || !pendingBuffGrants.isEmpty()) {
        // SINGLE per-tick grid pass — build index only if there are live infections.
        Map<String, int[]> infectedPositions = new HashMap<>();
        Map<String, Entity> infectedOccupants = new HashMap<>();
        if (!infections.isEmpty()) {
            int w = worldGrid.getWidth(), h = worldGrid.getHeight();
            for (int x = 0; x < w; x++) {
                for (int y = 0; y < h; y++) {
                    gridReadCountForTest++;
                    Cell c = worldGrid.getCell(x, y);
                    if (c.isEmpty()) continue;
                    String id = EntityIds.entityIdOf(c.occupant());
                    if (id == null) continue;
                    if (!infections.containsKey(id)) continue;
                    infectedPositions.put(id, new int[]{x, y});
                    infectedOccupants.put(id, c.occupant());
                }
            }
        }

        // Phase A: DoT damage + decrement + enqueue expiry cures as PendingGrant.
        boolean anyDamage = false;
        for (var entry : new HashMap<>(infections).entrySet()) {
            String id = entry.getKey();
            Infection inf = entry.getValue();
            int[] pos = infectedPositions.get(id);
            Entity occ = infectedOccupants.get(id);
            Position gridPos = pos == null ? inf.position() : new Position(pos[0], pos[1]);
            if (pos != null && occ != null) {
                int damage = inf.damagePerTick();
                int x = pos[0], y = pos[1];
                switch (occ) {
                    case Entity.Particle p ->
                            worldGrid.setEntity(x, y, p.withEnergy(Math.max(0, p.energy() - damage)));
                    case Entity.BondedPair bp ->
                            worldGrid.setEntity(x, y, bp.withEnergy(Math.max(0, bp.energy() - damage)));
                    case Entity.CompositeMember cm ->
                            worldGrid.setEntity(x, y, cm.withEnergy(Math.max(0, cm.energy() - damage)));
                    default -> { /* ignore */ }
                }
                anyDamage = true;
                inf = inf.withPosition(gridPos);
            }
            Infection next = inf.decrement();
            if (next.isExpired()) {
                // Codex HIGH cycle 3: PendingGrant carries its own Position + occupant snapshot.
                pendingBuffGrants.add(new PendingGrant(id, inf.initialTicks(), occ, gridPos));
                infections.remove(id);
            } else {
                infections.put(id, next);
            }
        }
        if (anyDamage) markEnvDamageApplied();

        // Phase B (Codex HIGH 4 + cycle 3): evaluate pending grants by POSITION, not via `infections`.
        // This means grants enqueued by reduceInfection earlier in the tick — whose target has
        // been removed from `infections` — are still evaluated here.
        for (PendingGrant pg : pendingBuffGrants) {
            Position p = pg.position();
            Cell postCell = worldGrid.getCell(p.x(), p.y());
            if (postCell.isEmpty()) continue;                 // target vacated the cell
            Entity postOcc = postCell.occupant();
            if (!isAliveEntity(postOcc)) continue;            // Codex HIGH 4: dead after damage → no buff
