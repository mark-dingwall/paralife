- **Toxin intensity scale (REVIEWS.md MEDIUM):** The shadow grid stores intensity as an unsigned byte 0..255 and damage formulas multiply by (intensity / 255.0) in Plan 02 — i.e., the 0..255 value is treated as a fraction in all damage math, so `splashFraction * (intensity/255.0) * maxSplash` — not `splashFraction * intensity` raw. <same_tick_death_model>
## Canonical Same-Tick Env-Death Model (Blocker 1 — referenced by Plans 02/03/04)

**Problem:** SimulationEngine.processDeaths runs at @Order(10). EnvironmentEngine runs at @Order(14) and applies damage. Without intervention, a zero-energy entity produced by env damage would survive the tick, be picked up by ActionResolver at @Order(20), and be perceived as alive by bots at @Order(50).

**Chosen approach: Option (a) — processEnvDeaths sweep at end of EnvironmentEngine.onTick.**

Rationale:
- Least invasive: no re-ordering of SimulationEngine or addition of a new @Order(15/16) component.
- Keeps SimulationEngine's early death pass (@Order(10)) as the canonical entry point and avoids splitting death logic across two files.
- Reuses the SAME death-finalisation helper (`clearEntityAndCompost` + `buffRegistry.unregisterEntity` + `environmentEngine.clearInfectionOnDeath`), exposed as a package-private method on SimulationEngine so EnvironmentEngine can call it OR (simpler) EnvironmentEngine exposes its own private `finaliseEnvDeath(int x, int y, String entityId)` that mirrors the helper's body — both are valid; Task 2 picks one and documents the choice in 14-01-SUMMARY.md.

**Contract (MUST be honored by Plans 02, 03, 04):**
- Env damage sites (toxin collisions, mutagen infection DoT, lightning inner-radius damage) write `entity.withEnergy(max(0, ...))` as normal.
- They do NOT individually clear entities — they rely on the `processEnvDeaths()` sweep at the end of EnvironmentEngine.onTick to finalise.
- `processEnvDeaths()` iterates the grid once, finds any occupant with `energy <= 0` / `!isAlive()`, and applies the unified death-finalisation:
  1. `buffRegistry.unregisterEntity(id)`
  2. `environmentEngine.clearInfectionOnDeath(id)` (no-op in Plan 01; filled by Plan 03)
  3. `applyCompost(new Position(x, y))`
  4. `worldGrid.clearEntity(x, y)`
- Same for BondedPair (both member ids cleaned) and CompositeMember (the member cell cleaned; composite-level degradation is SimulationEngine's responsibility on the NEXT tick via its own processDeaths — acceptable latency because compositeEnergyDistributor at @Order(15) will see the hole and panic-zone logic kicks in; not Plan 01's concern).

**Test (in 14-01 Task 2):** `EnvDeathSweepTest` creates a grid, places a Particle with energy=1, stamps toxin-like state that kills it (direct call to `environmentEngine.damageForTestAndSweep`), asserts `grid.getCell(x, y).isEmpty()` after `onTick`. Blocker 1 closed.

Plans 02/03/04 each carry an acceptance criterion that says "env damage does NOT perform its own clearEntity — relies on processEnvDeaths per 14-01 same-tick model."

package com.paralife.engine;

import com.paralife.engine.SeasonTracker.Season;
import com.paralife.world.Entity;
import org.springframework.boot.context.properties.ConfigurationProperties;

/**
 * Phase 14 environmental events config (D-48). All rates, radii, durations bound
 * under `paralife.simulation.events.*`. Nested records follow MetabolicProfile
 * pattern; validation in compact constructors throws IllegalArgumentException
 * matching SeasonsConfig/FertilityConfig style.
 *
 * <p>Season fields use `SeasonTracker.Season` enum — Spring Boot 3 binds
 * YAML strings (e.g. "SUMMER") to enum values automatically.
 */
@ConfigurationProperties(prefix = "paralife.simulation.events")
public record EnvironmentConfig(
        boolean enabled,
        Long seed,               // null = non-deterministic Random; set via @TestPropertySource in tests
        Lightning lightning,
        Toxin toxin,
        Mutagen mutagen,
        Compost compost
) {

    public record Lightning(
            Season peakSeason,
            double peakLambda,
            double offSeasonLambda,
            int innerRadius,
            int outerRadius,
            int damage,
            int fertilityBoost
    ) {
        public Lightning {
            if (peakSeason == null) throw new IllegalArgumentException("lightning.peakSeason required");
            if (peakLambda < 0.0 || peakLambda > 1.0) throw new IllegalArgumentException("lightning.peakLambda must be in [0,1]: " + peakLambda);
            if (offSeasonLambda < 0.0 || offSeasonLambda > 1.0) throw new IllegalArgumentException("lightning.offSeasonLambda must be in [0,1]: " + offSeasonLambda);
            if (peakLambda < offSeasonLambda) throw new IllegalArgumentException("lightning.peakLambda < offSeasonLambda: " + peakLambda + " < " + offSeasonLambda);
            if (innerRadius < 0) throw new IllegalArgumentException("lightning.innerRadius negative: " + innerRadius);
            if (outerRadius <= innerRadius) throw new IllegalArgumentException("lightning.outerRadius must be > innerRadius: " + outerRadius + " <= " + innerRadius);
            if (damage < 0) throw new IllegalArgumentException("lightning.damage negative: " + damage);
            if (fertilityBoost < 0) throw new IllegalArgumentException("lightning.fertilityBoost negative: " + fertilityBoost);
        }
    }

    public record Toxin(
            Season peakSeason,
            double peakLambda,
            double offSeasonLambda,
            int pathPointsMin,
            int pathPointsMax,
            int pathOffsetMin,
            int pathOffsetMax,
            int speed,
            int lifetimeTicks,
            int diffusionRadius,   // used by Plan 02 as the Moore-neighborhood radius for CA diffusion kernel
            double decayRate,
            double splashDamageFraction,
            int baseDamage,
            int intensityThreshold,
            Resistance resistance
    ) {
        public record Resistance(double catalyst, double membrane, double spore) {
            public Resistance {
                if (catalyst < 0) throw new IllegalArgumentException("toxin.resistance.catalyst negative: " + catalyst);
                if (membrane < 0) throw new IllegalArgumentException("toxin.resistance.membrane negative: " + membrane);
                if (spore < 0) throw new IllegalArgumentException("toxin.resistance.spore negative: " + spore);
            }
            /** Per-type multiplier (damage = baseDamage * (intensity/255.0) * multiplier). */
            public double multiplierFor(Entity.ParticleType type) {
                return switch (type) {
                    case CATALYST -> catalyst;
                    case MEMBRANE -> membrane;
                    case SPORE -> spore;
                };
            }
        }
        public Toxin {
            if (peakSeason == null) throw new IllegalArgumentException("toxin.peakSeason required");
            if (peakLambda < offSeasonLambda) throw new IllegalArgumentException("toxin.peakLambda < offSeasonLambda");
            if (pathPointsMin < 2) throw new IllegalArgumentException("toxin.pathPointsMin must be >= 2: " + pathPointsMin);
            if (pathPointsMax < pathPointsMin) throw new IllegalArgumentException("toxin.pathPointsMax < pathPointsMin");
            if (pathOffsetMin < 0) throw new IllegalArgumentException("toxin.pathOffsetMin negative");
            if (pathOffsetMax < pathOffsetMin) throw new IllegalArgumentException("toxin.pathOffsetMax < pathOffsetMin");
            if (speed < 1) throw new IllegalArgumentException("toxin.speed must be >= 1: " + speed);
            if (lifetimeTicks < 1) throw new IllegalArgumentException("toxin.lifetimeTicks must be >= 1: " + lifetimeTicks);
            if (diffusionRadius < 1) throw new IllegalArgumentException("toxin.diffusionRadius must be >= 1");
            if (decayRate < 0.0 || decayRate > 1.0) throw new IllegalArgumentException("toxin.decayRate must be in [0,1]: " + decayRate);
            if (splashDamageFraction < 0.0) throw new IllegalArgumentException("toxin.splashDamageFraction negative");
            if (baseDamage < 0) throw new IllegalArgumentException("toxin.baseDamage negative");
            if (intensityThreshold < 0 || intensityThreshold > 255) throw new IllegalArgumentException("toxin.intensityThreshold must be in [0,255]");
            if (resistance == null) throw new IllegalArgumentException("toxin.resistance required");
        }
    }

    public record Mutagen(
            Season peakSeason,
            double peakLambda,
            double offSeasonLambda,
            int infectionDurationMin,
            int infectionDurationMax,
            int buffDurationMultiplier,
            int cureTicks,
            int attackCureReduction,
            int damagePerTick,
            double strainMutationChance,
            double gossipProbability,
            int zoneDecayTicks         // Blocker 3: after `zoneDecayTicks` with no active mutagen event, strain cells cleared
    ) {
        public Mutagen {
            if (peakSeason == null) throw new IllegalArgumentException("mutagen.peakSeason required");
            if (peakLambda < offSeasonLambda) throw new IllegalArgumentException("mutagen.peakLambda < offSeasonLambda");
            if (infectionDurationMin < 1) throw new IllegalArgumentException("mutagen.infectionDurationMin must be >= 1");
            if (infectionDurationMax < infectionDurationMin) throw new IllegalArgumentException("mutagen.infectionDurationMax < min");
            if (buffDurationMultiplier < 1) throw new IllegalArgumentException("mutagen.buffDurationMultiplier must be >= 1");
            if (cureTicks < 0) throw new IllegalArgumentException("mutagen.cureTicks negative");
            if (attackCureReduction < 0) throw new IllegalArgumentException("mutagen.attackCureReduction negative");
            if (damagePerTick < 0) throw new IllegalArgumentException("mutagen.damagePerTick negative");
            if (strainMutationChance < 0.0 || strainMutationChance > 1.0) throw new IllegalArgumentException("mutagen.strainMutationChance must be in [0,1]");
            if (gossipProbability < 0.0 || gossipProbability > 1.0) throw new IllegalArgumentException("mutagen.gossipProbability must be in [0,1]");
            if (zoneDecayTicks < 1) throw new IllegalArgumentException("mutagen.zoneDecayTicks must be >= 1");
        }
    }

    public record Compost(int fullStrength, int halfStrength) {
        public Compost {
            if (fullStrength < 0) throw new IllegalArgumentException("compost.fullStrength negative: " + fullStrength);
            if (halfStrength < 0) throw new IllegalArgumentException("compost.halfStrength negative: " + halfStrength);
        }
    }

    public EnvironmentConfig {
        if (lightning == null) throw new IllegalArgumentException("lightning config missing");
        if (toxin == null) throw new IllegalArgumentException("toxin config missing");
        if (mutagen == null) throw new IllegalArgumentException("mutagen config missing");
        if (compost == null) throw new IllegalArgumentException("compost config missing");
    }

                true,
                null,
                new Lightning(Season.SUMMER, 0.04, 0.005, 2, 4, 40, 25),
                new Toxin(Season.AUTUMN, 0.03, 0.005, 4, 8, 5, 25, 3, 80, 3, 0.1,
                        0.2, 10, 16,

package com.paralife.engine;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

import java.util.List;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CopyOnWriteArrayList;

/**
 * Shadow registry for mutagen survivor buffs (D-19, D-47). Keyed by entity ID.
 * Mirrors BotRegistry / CompositeRegistry pattern. CopyOnWriteArrayList makes
 * per-entity buff lists safe to iterate from perception/action threads while
 * the tick thread mutates.
 *
 * <p>Buff semantics (REVIEWS.md LOW clarification): grant() DEDUPLICATES same
 * BuffType per entity. Granting the same BuffType twice does NOT stack
 * numerical effects; instead the second grant updates the existing ActiveBuff's
 * expiryTick to the later of the two. This matches the Plan 05 design where
 * hasBuff() is a boolean check, not a count.
 */
@Component
public class BuffRegistry {

    private static final Logger log = LoggerFactory.getLogger(BuffRegistry.class);

    public enum BuffType {
        ATTACK_PLUS_1,
        MOVEMENT_PLUS_1,
        SENSOR_PLUS_1,
        UPKEEP_MINUS_1
    }

    /** Immutable buff record (D-19). */
    public record ActiveBuff(BuffType type, long expiryTick) {}

    private final ConcurrentHashMap<String, CopyOnWriteArrayList<ActiveBuff>> byEntity =
            new ConcurrentHashMap<>();

    /**
     * Grant a buff. If the entity already has a buff of this type, update its
     * expiryTick to max(existing, new). No numerical stacking.
     */
    public void grant(String entityId, BuffType type, long expiryTick) {
        byEntity.compute(entityId, (k, existing) -> {
            var list = existing == null ? new CopyOnWriteArrayList<ActiveBuff>() : existing;
            // Dedup: find existing of same type and replace with later expiry; else append.
            for (int i = 0; i < list.size(); i++) {
                if (list.get(i).type() == type) {
                    long later = Math.max(list.get(i).expiryTick(), expiryTick);
                    list.set(i, new ActiveBuff(type, later));
                    log.debug("Buff refreshed (dedup): entity={} type={} expiresAt={}", entityId, type, later);
                    return list;
                }
            }
            list.add(new ActiveBuff(type, expiryTick));
            log.debug("Buff granted: entity={} type={} expiresAt={}", entityId, type, expiryTick);
            return list;
        });
    }

    public List<ActiveBuff> getBuffs(String entityId) {
        var list = byEntity.get(entityId);
        return list == null ? List.of() : list;
    }

    public boolean hasBuff(String entityId, BuffType type) {
        var list = byEntity.get(entityId);
        if (list == null) return false;
        for (ActiveBuff b : list) {
            if (b.type() == type) return true;
        }
        return false;
    }

    /**
     * Remove all buffs whose expiryTick <= currentTick. Called each tick from
     * EnvironmentEngine.
     */
    public void expireBuffs(long currentTick) {
        byEntity.forEach((id, list) -> list.removeIf(b -> b.expiryTick() <= currentTick));
        byEntity.entrySet().removeIf(e -> e.getValue().isEmpty());
    }

    /**
     * Called from SimulationEngine.processDeaths on every entity clear (Pitfall 5).
     */
    public void unregisterEntity(String entityId) {
        byEntity.remove(entityId);
    }

    /** Test-only: reset all state. */
    public void clear() {
        byEntity.clear();
    }
}
