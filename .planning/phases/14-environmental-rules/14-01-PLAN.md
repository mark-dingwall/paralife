## Revision Notes (reviews cycle)

This revision addresses Codex HIGH 1 (env-death cleanup incomplete — bot registry + composite registry not updated same tick) and Codex MEDIUM (full-grid scan every tick when no env damage applied).

**Core change:** introduce a new `DeathFinalizer` @Component that is the single canonical death path used by BOTH `SimulationEngine` (existing death sites) AND `EnvironmentEngine.processEnvDeaths` (new env-death path). This guarantees composite registry + bot registry + buff registry + infection cleanup + compost + clearEntity all run identically regardless of which subsystem caused the death.

- Codex HIGH 1: `DeathFinalizer.finalizeCompositeMemberDeath` wraps the same `handleMemberDeath` logic (composite dissolution/degradation/panic-zone) so env-killed composite members update `CompositeRegistry` same tick, BEFORE `CompositeEnergyDistributor` (@Order 15) and `ActionResolver` (@Order 20) run.
- Codex HIGH 1: Every env-death path calls `botRegistry.unregisterByEntity(id)` via `DeathFinalizer` — stale sessions cannot linger.
- Codex MEDIUM: `processEnvDeaths` gated on `envDamageAppliedThisTick` flag. The flag is set by any env damage site (Plans 02/03/04 call `environmentEngine.markEnvDamageApplied()` after writing `withEnergy(max(0, ...))`). When no env damage occurred, the full-grid scan is skipped.

<deviations>
- **R13 "Cell flags system":** REQUIREMENTS.md R13 reads "Environmental effects use Cell flags system (extending FLAG_OVERCROWDED pattern)." This phase delivers the effect via **shadow grids + cellStatus/entityStatus byte projection on CellView**, which satisfies the spirit (extensible bit-based environmental state visible to perception) while providing intensity-valued representation that cell flags alone cannot. Cell.FLAG_OVERCROWDED continues to populate `CellView.flags` unchanged for server-authoritative overcrowding. The new cellStatus bits (OVERCROWDED_vision-scoped, TOXIN_PRESENT, MUTAGEN_ZONE) and entityStatus bits (STARVING, TOXIC, MUTATING, BUFFED) are the flag-system extension. No new Cell.FLAG_* constants for TOXIC/MUTAGEN are added (shadow-grid-origin, CellView-status-destination).
- **@Lazy dropped (REVIEWS.md LOW):** SimulationEngine → DeathFinalizer → EnvironmentEngine is NOT a circular dependency at construction. SimulationEngine holds a `DeathFinalizer`; DeathFinalizer holds BOTH SimulationEngine (for `dissolveOrRevert` callback) AND EnvironmentEngine (for compost/infection cleanup). To prevent a Spring init cycle, DeathFinalizer injects SimulationEngine with `@Lazy` ONLY IF Spring reports a cycle at startup; otherwise direct injection is preferred. The SUMMARY records the actual choice.
- **No global application-test.yml override (Codex HIGH 1 for Plan 06):** Plan 01 does NOT create `src/test/resources/application-test.yml` with env.enabled=true. Tests use `@TestPropertySource(properties = { "paralife.simulation.events.enabled=true", "paralife.simulation.events.seed=42" })` at the class level.
- **Toxin intensity scale:** The shadow grid stores intensity as an unsigned byte 0..255 and damage formulas in Plan 02 multiply by `(intensity / 255.0)` — not the raw byte.
</deviations>

## Canonical Same-Tick Env-Death Model (Codex HIGH 1)

**Problem:** SimulationEngine.processDeaths runs at @Order(10). EnvironmentEngine runs at @Order(14) and applies damage. Without intervention, a zero-energy entity produced by env damage would (a) survive the tick, (b) be picked up by ActionResolver at @Order(20), and (c) be perceived as alive by bots at @Order(50). Worse, a dead CompositeMember would leave a stale `CompositeRegistry` entry that CompositeEnergyDistributor at @Order(15) reads IMMEDIATELY.

**Chosen approach:** Option (a) — `processEnvDeaths()` as the final step of `EnvironmentEngine.onTick`, delegating to the shared `DeathFinalizer` @Component so the same cleanup runs whether the death came from combat (SimulationEngine) or env damage (EnvironmentEngine).

**Contract (MUST be honored by Plans 02, 03, 04):**
- Env damage sites (toxin collisions, mutagen infection DoT, lightning inner-radius damage) write `entity.withEnergy(max(0, ...))` as normal AND call `environmentEngine.markEnvDamageApplied()` if the write MAY have lethaled an occupant.
- They do NOT individually clear entities — they rely on the `processEnvDeaths()` sweep at the end of EnvironmentEngine.onTick to finalise.
- `processEnvDeaths()` short-circuits when `envDamageAppliedThisTick` is false (Codex MEDIUM).
- When it does run, it iterates the grid once and for every occupant with `!isAlive()`:
  - Particle → `deathFinalizer.finalizeParticleDeath(x, y, p)` — handles bot registry + buff registry + infection + compost + clearEntity.
  - BondedPair → `deathFinalizer.finalizeBondedPairDeath(x, y, bp)` — same, for both member ids.
  - CompositeMember → `deathFinalizer.finalizeCompositeMemberDeath(x, y, cm)` — same PLUS composite registry update same-tick. If the composite reaches memberCount 0 (dissolve) or 1 (revert), DeathFinalizer calls back into `simulationEngine.dissolveOrRevert(compositeId)` which reuses the existing SimulationEngine methods.

**Test (in 14-01 Task 3):** `EnvDeathSweepTest` contains two assertions:
1. Particle env-death: place Particle, call `env.killParticleAtForTest(x,y)`, call `env.processEnvDeathsForTest()` → assert `grid.getCell(x,y).isEmpty()` AND `botRegistry.getBySession(sessionId).isEmpty()`.
2. CompositeMember env-death: create a 3-member composite, call `env.killCompositeMemberAtForTest(...)`, call `env.processEnvDeathsForTest()` → assert the composite in registry now has 2 members (or has degraded/dissolved per the canonical rules), NOT 3.

Plans 02/03/04 each carry an acceptance criterion that says "env damage does NOT perform its own clearEntity — relies on processEnvDeaths per 14-01 same-tick model AND calls environmentEngine.markEnvDamageApplied() before the end of collision resolution."

 * simulation — whether caused by combat (SimulationEngine.processDeaths),
 * panic-zone collapse (SimulationEngine.checkPanicZone), or environmental
 * damage (EnvironmentEngine.processEnvDeaths) — MUST route through this

 *   <li>EnvironmentEngine infection-map cleanup</li>

public class DeathFinalizer {

    private static final Logger log = LoggerFactory.getLogger(DeathFinalizer.class);

    private final WorldGrid worldGrid;
    private final BotRegistry botRegistry;
    private final BuffRegistry buffRegistry;
    private final CompositeRegistry compositeRegistry;
    private final EnvironmentEngine environmentEngine;
    private final SimulationEngine simulationEngine;

    public DeathFinalizer(WorldGrid worldGrid,
                          BotRegistry botRegistry,
                          BuffRegistry buffRegistry,
                          CompositeRegistry compositeRegistry,
                          EnvironmentEngine environmentEngine,
                          @Lazy SimulationEngine simulationEngine) {
        this.worldGrid = worldGrid;
        this.botRegistry = botRegistry;
        this.buffRegistry = buffRegistry;
        this.compositeRegistry = compositeRegistry;
        this.environmentEngine = environmentEngine;
        this.simulationEngine = simulationEngine;

        botRegistry.unregisterByEntity(p.id());
        buffRegistry.unregisterEntity(p.id());
        environmentEngine.clearInfectionOnDeath(p.id());
        environmentEngine.applyCompost(new Position(x, y));
        worldGrid.clearEntity(x, y);
    }

    public void finalizeBondedPairDeath(int x, int y, BondedPair bp) {
        botRegistry.unregisterByEntity(bp.primaryEntityId());
        botRegistry.unregisterByEntity(bp.secondaryEntityId());
        buffRegistry.unregisterEntity(bp.primaryEntityId());
        buffRegistry.unregisterEntity(bp.secondaryEntityId());
        environmentEngine.clearInfectionOnDeath(bp.primaryEntityId());
        environmentEngine.clearInfectionOnDeath(bp.secondaryEntityId());
        environmentEngine.applyCompost(new Position(x, y));
        worldGrid.clearEntity(x, y);

    /**
     * CompositeMember death — full canonical path matching
     * SimulationEngine.handleMemberDeath:
     * <ol>
     *   <li>bot + buff + infection + compost cleanup</li>
     *   <li>compositeRegistry.removeMember(compositeId, id)</li>
     *   <li>worldGrid.clearEntity</li>
     *   <li>Look up composite; if memberCount == 0 or 1, delegate to
     *       {@link SimulationEngine#dissolveOrRevertForDeathFinalizer}
     *       which handles dissolve / revertToBondedPair in place.</li>
     * </ol>
     *
     * @param processedComposites set used by SimulationEngine to prevent double-processing
     *                            across multiple death passes in the same tick. Env-death
     *                            callers pass a fresh {@code new HashSet<>()}; SimulationEngine's
     *                            death loop passes its existing set.
     */
    public void finalizeCompositeMemberDeath(int x, int y, CompositeMember cm,
                                              Set<String> processedComposites) {
        String memberId = cm.id();
        String compositeId = cm.compositeId();

        botRegistry.unregisterByEntity(memberId);
        buffRegistry.unregisterEntity(memberId);
        environmentEngine.clearInfectionOnDeath(memberId);
        environmentEngine.applyCompost(new Position(x, y));

        var compositeOpt = compositeRegistry.getComposite(compositeId);
        if (compositeOpt.isEmpty() || processedComposites.contains(compositeId)) {
            worldGrid.clearEntity(x, y);
            return;
        }

        compositeRegistry.removeMember(compositeId, memberId);
        worldGrid.clearEntity(x, y);

        var composite = compositeOpt.get();
        int remaining = composite.getMemberCount();
        if (remaining <= 1) {
            simulationEngine.dissolveOrRevertForDeathFinalizer(compositeId, processedComposites);
        }
        // remaining >= 2: SimulationEngine's existing graceful-degradation / dissolution roll
        // runs on the next combat tick via its own processDeaths pass.
    }

    /** Convenience overload for env-death callers. */
    public void finalizeCompositeMemberDeath(int x, int y, CompositeMember cm) {
        finalizeCompositeMemberDeath(x, y, cm, new HashSet<>());
    }
}
