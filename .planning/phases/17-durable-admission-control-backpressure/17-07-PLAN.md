**REVIEWS-driven changes vs initial plan (consensus HIGH):**
1. **STALLED-aware `afterConnectionClosed` (claude HIGH / codex HIGH).** Initial plan called `cleanupBot(session.getId())` unconditionally on every close, including the close that follows `E|408|reconnect-required`. Result: entity reaped before grace window could recover it. New design: `if (isStalled(session)) { detach + unregister WS only — entity stays in grid, ResumeTokenRegistry.sweep is the sole reaper }`.
2. **Idempotent `markStalled` (codex HIGH).** Initial plan would re-fire on every overflow callback. Combined with Plan 06's per-session fire-once guard, the handler also short-circuits if `ATTR_STALL_TICK` already set.

```java
/**
 * Phase 17 D-13: rebind an existing entity (preserved across STALLED-pivot) to a new
 * WebSocket session. Removes the prior session→entity record (if any) and the prior
 * entity→session reverse record, then inserts the new session→entity record using the
 * SAME BotState (position, species, etc.) — only the session id changes.
 *
 * <p>If {@code entityId} is unknown, this is a no-op (returns false). Otherwise returns true.
 *
 * @throws IllegalStateException if the new sessionId is already bound to a different entity
 */
public synchronized boolean rebindSession(String newSessionId, String entityId) {
    Objects.requireNonNull(newSessionId, "newSessionId");
    Objects.requireNonNull(entityId, "entityId");
    String oldSessionId = entityToSession.get(entityId);
    if (oldSessionId == null) return false;

    BotState existing = bySession.get(oldSessionId);
    if (existing == null) return false;

    // Defensive: refuse to clobber a different entity that may already be bound to newSessionId.
    BotState collision = bySession.get(newSessionId);
    if (collision != null && !collision.entityId().equals(entityId)) {
        throw new IllegalStateException("rebindSession: " + newSessionId
                + " already bound to entity=" + collision.entityId()
                + "; refusing to clobber for entity=" + entityId);
    }

    bySession.remove(oldSessionId);
    bySession.put(newSessionId, existing.withSessionId(newSessionId));   // see note
    entityToSession.put(entityId, newSessionId);
    return true;
}
```

**Step 9 — IDEMPOTENT `markStalled` with out-of-band 408 + post-detach close (CODEX HIGH)**

```java
/**
 * Idempotent: if {@code session} is already stalled, returns immediately. Otherwise:
 * 1. Set ATTR_STALL_TICK and resolve the ACTIVE resume token (cached on session attrs).
 * 2. Snapshot respawn count for restore-on-rebind.
 * 3. Convert the ACTIVE token to STALLED via ResumeTokenRegistry.convertToStalled.
 * 4. Detach the OutboundSender (joins the VT for up to 100ms).
 * 5. Send 408 OUT-OF-BAND (direct sendMessage post-detach) — guaranteed delivery even though queue was saturated.
 * 6. Close the WS with SERVICE_RESTARTED.
 *
 * <p>Steps 4-5 ordering is critical: detach first so the sender VT has stopped writing, then the
 * inbound thread can safely call sendMessage directly. Plan 06's t.join(100) bounds the race window.
 */
public void markStalled(WebSocketSession session, long stallTick) {
    if (session == null) return;
    var attrs = session.getAttributes();

    // Idempotent guard (codex HIGH): if already STALLED, do nothing.
    if (attrs.containsKey(ATTR_STALL_TICK)) return;

    attrs.put(ATTR_STALL_TICK, stallTick);
    Object entityIdObj = attrs.remove(ATTR_ENTITY_ID);
    String entityId = entityIdObj == null ? null : entityIdObj.toString();
    Object tokenObj = attrs.get(ATTR_RESUME_TOKEN);
    String activeToken = tokenObj == null ? null : tokenObj.toString();

    // Snapshot respawn count so rebind can restore it (claude MEDIUM).
    if (entityId != null) {
        respawnCountAtStall.put(entityId, respawnCountOf(attrs));
    }

    // Convert ACTIVE -> STALLED in registry.
    if (activeToken != null) {
        resumeTokenRegistry.convertToStalled(activeToken, stallTick);
    } else if (entityId != null) {
        log.warn("markStalled: session={} entity={} has no cached resume token; entity will be unrecoverable",
                session.getId(), entityId);
    }

    // Detach sender VT FIRST (joins for up to 100ms per Plan 06).
    outboundSender.detachSession(session.getId());

    // Now safe to write directly: VT has joined, no concurrent writer.
    sendOutOfBand(session, new Frame.ErrorFrame(408, Optional.of(RejectionToken.RECONNECT_REQUIRED)));

    // Close the WS to force the client into reconnect/resume flow.
    try { session.close(CloseStatus.SERVICE_RESTARTED); } catch (IOException ignored) {}
}

/**
 * Direct synchronized send — used ONLY when the queue is bypassed (markStalled / stalled-inbound 408).
 * Safe to call AFTER outboundSender.detachSession completes its 100ms join.
 */
private void sendOutOfBand(WebSocketSession session, Frame frame) {
    if (session == null || !session.isOpen()) return;
    try {
        String encoded = PerceptionCodec.encode(frame);
        synchronized (session) {
            session.sendMessage(new TextMessage(encoded));
        }
    } catch (IOException | RuntimeException e) {
        log.warn("Out-of-band send failed for {}: {}", session.getId(), e.getMessage());
    }
}
```
