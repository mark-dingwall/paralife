<objective>
Extend the compact-text codec to support the new resume-token slot on `r|` (client → server) and `S|` (server → client) frames. **This is the critical codec blocker** — without it, no Phase 17 work that issues or receives a resume token can run end-to-end.

Purpose: The current `parseRegister` strictly enforces `c.atEnd()` after the entity-type char and throws `CodecException` on any trailing content. Phase 17's resume-token wire shape (`r|C|r:<16hex>`, `S|<entityId>|r:<16hex>`) requires this enforcement to be relaxed and the optional slot threaded through both directions.

**Locked design (D-13 + REVIEWS consensus):** all resume tokens carry the literal `r:` sentinel prefix (e.g. `r:0a1b2c3d4e5f6789`, total 18 chars on wire). The disambiguator in `parseSync` is then trivially deterministic: **second slot starts with `r:` → token; otherwise → effects** (regardless of effect block grammar). This avoids the broken "starts-with-`f`-then-digit" heuristic flagged by claude review (the `f` BLOCK prefix is in TickFrame; `SyncFrame` effects per `15-SCHEMA.md` §6.2 vector 10 are bare `S:`/`I:`/`f...`, so a content-shape heuristic was unsound).

Output: Updated `Frame.RegisterFrame` and `Frame.SyncFrame` records (each gains `Optional<String> resumeToken`), updated codec parse/encode methods, and round-trip codec tests covering all four cardinalities (with/without token × with/without effects).
</objective>

**Disambiguator rule (LOCKED — sole source of truth):**

Resume tokens are minted by `ResumeTokenRegistry` (Plan 05) as `String.format("r:%016x", ThreadLocalRandom.current().nextLong())` — always 18 chars, always begin with the literal two-char sequence `r:`. No effect block can begin with `r:` (effect grammar per `15-SCHEMA.md` §6.2 / §8.3 starts with one of `S`, `I`, `f`, `T`, ... — never `r`). Therefore:

- After consuming the `|` that follows entityId in a Sync frame, peek the next two chars.
- If they are exactly `r:` → consume up to next `|` or end → that string IS the resume token.
- Otherwise → the remainder is the effect list (delegate to existing `parseEffectList`).

This is the ENTIRE disambiguator. Do not inspect `f` or any other effect-grammar char. Do not call `parseEffectList` speculatively.

```java
private static Frame.RegisterFrame parseRegister(ParseCursor c) {
    char t = c.next();
    if (t != 'C' && t != 'M' && t != 'S') {
        throw new CodecException("Register entityType must be C/M/S at " + (c.index() - 1) + ": " + t);
    }
    Optional<String> resumeToken = Optional.empty();
    if (!c.atEnd()) {
        if (c.peek() != '|') {
            throw new CodecException("Register frame: expected '|' or end at " + c.index() + ", got: " + c.peek());
        }
        c.next();                       // consume '|'
        String token = c.readUntil('|', false);   // reads to '|' or end-of-input
        if (token.isEmpty()) {
            throw new CodecException("Register frame: empty resume-token at " + c.index());
        }
        if (!token.startsWith(RESUME_TOKEN_SENTINEL)) {
            throw new CodecException("Register resume-token must start with 'r:' at " + c.index() + ": " + token);
        }
        resumeToken = Optional.of(token);
    }
    return new Frame.RegisterFrame(t, resumeToken);
}
```

```java
private static Frame.SyncFrame parseSync(ParseCursor c) {
    String entityId = c.readUntil('|', false);
    if (entityId.isEmpty()) throw new CodecException("Sync entityId missing at " + c.index());

    Optional<String> resumeToken = Optional.empty();
    List<ActiveEffect> effects = List.of();

    if (!c.atEnd() && c.peek() == '|') {
        c.next();   // consume first '|' after entityId
        if (c.atEnd()) {
            throw new CodecException("Sync second slot empty at " + c.index());
        }
        // Sole disambiguator: second slot starts with 'r:' => token; otherwise => effects.
        if (peekStartsWithSentinel(c, RESUME_TOKEN_SENTINEL)) {
            String token = c.readUntil('|', false);
            if (token.isEmpty()) throw new CodecException("Sync resume-token empty at " + c.index());
            resumeToken = Optional.of(token);
            // Optional second slot: |<effects>
            if (!c.atEnd() && c.peek() == '|') {
                c.next();   // consume '|'
                effects = parseEffectList(c);
            }
        } else {
            effects = parseEffectList(c);
        }
    }
    return new Frame.SyncFrame(entityId, resumeToken, effects);
}

/**
 * Non-consuming check: does the cursor's remaining buffer start with {@code prefix}?
 * Implementation MUST NOT advance the cursor. If ParseCursor exposes index/setIndex,
 * snapshot+restore. Otherwise, re-implement via charAt on the underlying buffer if
 * accessible; failing that, replace this method's body with the cursor's existing
 * peek/peekAt idiom (read ParseCursor.java first to choose).
 */
private static boolean peekStartsWithSentinel(ParseCursor c, String prefix) {
    int idx = c.index();
    try {
        for (int i = 0; i < prefix.length(); i++) {
            if (c.atEnd()) return false;
            if (c.next() != prefix.charAt(i)) return false;
        }
        return true;
    } finally {
        c.setIndex(idx);   // ALWAYS restore; never consume on a peek
    }
}
```
