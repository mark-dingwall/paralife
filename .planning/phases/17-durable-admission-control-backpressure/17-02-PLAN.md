Extend the compact-text codec to support the new resume-token slot on `r|` (client → server) and `S|` (server → client) frames. **This is the critical codec blocker** — without it, no Phase 17 work that issues or receives a resume token can run end-to-end.

Phase 17's resume-token wire shape (`r|C|<token>`, `S|<entityId>|<token>`) requires this enforcement to be relaxed and the optional slot threaded through both directions.

Output: Updated `Frame.RegisterFrame` and `Frame.SyncFrame` records (each gains `Optional<String> resumeToken`), updated codec parse/encode methods, and round-trip codec tests covering all four cardinalities (with/without token × with/without effects).

**Effects-list disambiguation:** per `15-SCHEMA.md` §8.3, the effect-list block begins with the literal `f` prefix. The resume-token is opaque hex (16 chars `[0-9a-f]+`). On `S|<entityId>|<???>`, the next char after the second `|` distinguishes:
- starts with `f` followed by digit → effect block (current shape) → no token, parse effects
- otherwise → token (read until next `|` or end), then optionally `|f...` effects.

Concretely: `S|abc|f5...` is `(abc, no-token, effects=[...])`; `S|abc|deadbeef|f5...` is `(abc, token=deadbeef, effects=[...])`; `S|abc|deadbeef` is `(abc, token=deadbeef, no-effects)`.

Update `parseSync` to disambiguate token-vs-effects after entityId. Effects always begin with `f` followed by a digit per SCHEMA §8.3. Resume token is opaque hex (16 chars), starts with `[0-9a-f]`. The disambiguator is: peek the first char of the second slot. If it is `f` AND the next char (if any) is `[0-9]`, treat as effects; otherwise treat as token. Implement as:

```java
private static Frame.SyncFrame parseSync(ParseCursor c) {
    String entityId = c.readUntil('|', false);
    if (entityId.isEmpty()) throw new CodecException("Sync entityId missing at " + c.index());

    Optional<String> resumeToken = Optional.empty();
    List<ActiveEffect> effects = List.of();

    if (!c.atEnd() && c.peek() == '|') {
        c.next();   // consume first '|' after entityId
        // Peek to disambiguate: effect block starts with 'f' then digit; token is hex (no 'f<digit>' shape).
        if (looksLikeEffectBlock(c)) {
            effects = parseEffectList(c);
        } else {
            // Read token up to next '|' or end of input.
            String token = c.readUntil('|', false);
            if (token.isEmpty()) throw new CodecException("Sync resume-token empty at " + c.index());
            resumeToken = Optional.of(token);
            // Optional second slot: |f<effects>
            if (!c.atEnd() && c.peek() == '|') {
                c.next();   // consume '|'
                effects = parseEffectList(c);
            }
        }
    }
    return new Frame.SyncFrame(entityId, resumeToken, effects);
}

/** Effect block starts with literal 'f' followed by an ASCII digit. */
private static boolean looksLikeEffectBlock(ParseCursor c) {
    if (c.atEnd() || c.peek() != 'f') return false;
    // Two-char lookahead: peek char after 'f'. Use cursor's index/snapshot if available;
    // if ParseCursor lacks two-char peek, save index, read 'f', peek next, restore.
    int idx = c.index();
    c.next();
    boolean isEffect = !c.atEnd() && Character.isDigit(c.peek());
    c.setIndex(idx);   // restore — assumes cursor exposes setIndex(); if not, copy this lookahead via c.snapshot() / c.restore()
    return isEffect;
}
```

If `ParseCursor` does not expose `setIndex` or snapshot/restore, instead read the cursor's current index, perform the peek with a temporary copy, and discard. **Read `ParseCursor.java` first to confirm available API**; pick the idiom already used elsewhere in `parseEffectList` for backtracking. If no backtracking primitive exists, add one minimal helper inside `PerceptionCodec` (e.g. `private static int snapshot(ParseCursor c) { return c.index(); }`) — but only if strictly necessary. The simplest fallback: scan the remainder once into a `String`, then split on `|` and route by content shape (token = no leading `f<digit>`, effects = leading `f<digit>`).
