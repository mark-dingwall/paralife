    ```java
    /**
     * Create a BondedPair with cached hybrid vigor rates (D-05, D-06).
     * Rates computed once at formation and stored — no per-tick randomness.
     */
    public static BondedPair formBond(String id, Particle primary, Particle secondary,
            MetabolicProfile metabolicProfile, BondingConfig bondingConfig) {
        var profileA = metabolicProfile.forType(primary.type());
        var profileB = metabolicProfile.forType(secondary.type());
        ThreadLocalRandom rng = ThreadLocalRandom.current();

        int maxEnergy = profileA.maxEnergy() + profileB.maxEnergy(); // D-07
        int combinedEnergy = primary.energy() + secondary.energy();

        // D-06: Bond decay cost = sum(A,B) * random(costMin, costMax)
        int effectiveDecay = bondDecayCost(
            profileA.decayPerTick(), profileB.decayPerTick(),
            bondingConfig.bondDecayCostMin(), bondingConfig.bondDecayCostMax(), rng);

        // D-05: Hybrid vigor for combat transfer
        int effectiveCombat = hybridRate(
            profileA.combatEnergyTransfer(), profileB.combatEnergyTransfer(),
            bondingConfig.bondRateBonusMin(), bondingConfig.bondRateBonusMax(), rng);

        // D-05: Hybrid vigor for attack power
        int effectiveAttack = hybridRate(
            profileA.attackPower(), profileB.attackPower(),
            bondingConfig.bondRateBonusMin(), bondingConfig.bondRateBonusMax(), rng);

        return new BondedPair(id, primary.type(), secondary.type(),
            combinedEnergy, maxEnergy, primary.id(), secondary.id(),
            effectiveDecay, effectiveCombat, effectiveAttack);
    }

    /** Hybrid vigor (D-05): rate = avg + (max-avg) * random(bonusMin, bonusMax) */
    private static int hybridRate(int rateA, int rateB, double bonusMin, double bonusMax, ThreadLocalRandom rng) {
        int avg = (rateA + rateB) / 2;
        int max = Math.max(rateA, rateB);
        // Guard: if min==max, use min directly (avoids ThreadLocalRandom.nextDouble exception)
        double bonus = (bonusMin == bonusMax) ? bonusMin : rng.nextDouble(bonusMin, bonusMax);
        return avg + (int)((max - avg) * bonus);
    }

    /** Bond decay cost (D-06): bondedDecay = sum(A,B) * random(costMin, costMax) */
    private static int bondDecayCost(int decayA, int decayB, double costMin, double costMax, ThreadLocalRandom rng) {
        // Guard: if min==max, use min directly
        double factor = (costMin == costMax) ? costMin : rng.nextDouble(costMin, costMax);
        return Math.max(1, (int)((decayA + decayB) * factor)); // at least 1 decay
    }
    ```

    **CRITICAL DESIGN CHANGE (addresses review concern #2 — stale flag correctness):**

    Starvation combat modifiers are computed from **current energy** at the point of application, NOT by reading FLAG_STARVING.     **Per D-09:** Add starvation intensity computation as a static method on `StarvationConfig`:
    ```java
    /**
     * Compute starvation intensity (D-09). Returns 0.0 if not starving, up to 1.0 at floor.
     * starvationIntensity = (threshold - currentPercent) / (threshold - floorPercent), clamped [0.0, 1.0]
     *
     * IMPORTANT: This is called directly from current energy values wherever modifiers are
     * needed (combat, consume). FLAG_STARVING is set separately for observability only.
     * This design avoids the stale-flag problem (review concern #2).
     */
    public static double computeIntensity(int energy, int maxEnergy, int thresholdPercent, int floorPercent) {
        double currentPercent = (double) energy / maxEnergy * 100;
        if (currentPercent >= thresholdPercent) return 0.0;
        if (thresholdPercent == floorPercent) return 1.0; // avoid division by zero
        double intensity = (thresholdPercent - currentPercent) / (double)(thresholdPercent - floorPercent);
        return Math.clamp(intensity, 0.0, 1.0);
    }
    ```
