    ### Part A — `src/main/java/com/paralife/websocket/JettyDeflateCustomizer.java` (new)

    Produces a customized `JettyRequestUpgradeStrategy` that the existing `WebSocketConfig` consumes. The strategy:
    - Refuses the upgrade when the client request lacks a `permessage-deflate` extension (D-33 server side, threat T-15-02).
    - Forces `server_no_context_takeover` on the negotiated response (D-31).
    - Leaves all session/handler lifecycle to Spring — no adapter, no session wrapping, no `JettyWebSocketSession(Map.of())`.

    ```java
    package com.paralife.websocket;

    import org.eclipse.jetty.websocket.core.ExtensionConfig;
    import org.slf4j.Logger;
    import org.slf4j.LoggerFactory;
    import org.springframework.context.annotation.Bean;
    import org.springframework.context.annotation.Configuration;
    import org.springframework.web.socket.server.jetty.JettyRequestUpgradeStrategy;

    import java.util.List;

    /**
     * Enforces {@code permessage-deflate; server_no_context_takeover} on every
     * WebSocket upgrade Spring performs (only path is {@code /ws/world}). The
     * customized {@link JettyRequestUpgradeStrategy} is injected into
     * {@link WebSocketConfig} via {@code setRequestUpgradeStrategy} on
     * {@code DefaultHandshakeHandler}.
     *
     * <p>D-33 fail-fast: the strategy's pre-upgrade hook inspects
     * {@code Sec-WebSocket-Extensions}. When absent, the handshake completes with
     * HTTP 400 and the session never opens.
     *
     * <p>There is exactly one wiring path at {@code /ws/world} — see
     * {@link WebSocketRouteAssertion} which verifies this invariant at
     * ApplicationReadyEvent.
     */
    @Configuration
    public class JettyDeflateCustomizer {

        private static final Logger log = LoggerFactory.getLogger(JettyDeflateCustomizer.class);
        static final String EXTENSION = "permessage-deflate";
        static final String NO_CONTEXT = "server_no_context_takeover";

        @Bean
        public JettyRequestUpgradeStrategy jettyRequestUpgradeStrategy() {
            JettyRequestUpgradeStrategy strategy = new JettyRequestUpgradeStrategy();
            strategy.addWebSocketConfigurer(container -> {
                // Register a server-side negotiator that inspects requested extensions
                // on every upgrade and enforces D-33.
                container.setCreator((req, resp, callback) -> {
                    List<ExtensionConfig> requested = req.getExtensions();
                    boolean hasDeflate = requested.stream()
                            .anyMatch(e -> EXTENSION.equalsIgnoreCase(e.getName()));
                    if (!hasDeflate) {
                        log.warn("Rejecting /ws/world upgrade from {} — no permessage-deflate",
                                req.getRemoteSocketAddress());
                        resp.setStatus(400);
                        callback.succeeded();
                        return null;
                    }
                    ExtensionConfig negotiated = new ExtensionConfig(EXTENSION);
                    negotiated.setParameter(NO_CONTEXT);
                    resp.setExtensions(List.of(negotiated));
                    // Returning null lets Spring's DefaultHandshakeHandler provide the
                    // handler-side object — we are ONLY customizing negotiation.
                    return null;
                });
            });
            return strategy;
        }
    }
    ```

    Notes for the implementer:
    - The exact customizer method on `JettyRequestUpgradeStrategy` varies between Spring Framework 6.1 / 6.2. If `addWebSocketConfigurer` does not resolve, use the `addProtocolHandler` / `setHandshakeTimeout` pair + access the underlying `ServerWebSocketContainer` via `JettyRequestUpgradeStrategy.getContainer()` (available in Spring 6.1+). The important behaviour is: customize negotiation before Spring's `DefaultHandshakeHandler.doHandshake()` runs.

The key invariant — only one path at `/ws/world` — is maintained by NOT calling `container.addMapping(PATH, ...)`. Spring's upgrade filter already owns the mapping; the customizer only replaces the negotiator on that mapping.
    - Do NOT use `new JettyWebSocketSession(Map.of())` anywhere. That sketch is gone.

    ```java
    package com.paralife.websocket;

    import org.springframework.context.annotation.Configuration;
    import org.springframework.web.socket.config.annotation.EnableWebSocket;
    import org.springframework.web.socket.config.annotation.WebSocketConfigurer;
    import org.springframework.web.socket.config.annotation.WebSocketHandlerRegistry;
    import org.springframework.web.socket.server.support.DefaultHandshakeHandler;
    import org.springframework.web.socket.server.jetty.JettyRequestUpgradeStrategy;

    /**
     * Spring owns the only /ws/world registration. Extension negotiation
     * (permessage-deflate; server_no_context_takeover) is injected via the
     * {@link JettyRequestUpgradeStrategy} produced by {@link JettyDeflateCustomizer}.
     *
     * <p>This is the ONLY wiring path — there is no native Jetty {@code addMapping}
     * for the same route. See {@link WebSocketRouteAssertion} for the runtime
     * invariant check.
     */
    @Configuration
    @EnableWebSocket
    public class WebSocketConfig implements WebSocketConfigurer {

        private final WorldWebSocketHandler worldWebSocketHandler;
        private final JettyRequestUpgradeStrategy upgradeStrategy;

        public WebSocketConfig(WorldWebSocketHandler worldWebSocketHandler,
                               JettyRequestUpgradeStrategy upgradeStrategy) {
            this.worldWebSocketHandler = worldWebSocketHandler;
            this.upgradeStrategy = upgradeStrategy;
        }

        @Override
        public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
            DefaultHandshakeHandler handshake = new DefaultHandshakeHandler(upgradeStrategy);
            registry.addHandler(worldWebSocketHandler, "/ws/world")
                    .setHandshakeHandler(handshake)
                    .setAllowedOrigins("*");
        }
    }
    ```

    import org.junit.jupiter.api.Test;
    import org.springframework.boot.test.context.SpringBootTest;
    import org.springframework.boot.test.web.server.LocalServerPort;
    import org.springframework.test.context.TestPropertySource;

    import java.net.URI;
    import java.net.http.HttpClient;
    import java.net.http.HttpRequest;
    import java.net.http.HttpResponse;
    import java.net.http.HttpResponse.BodyHandlers;

    import static org.junit.jupiter.api.Assertions.assertEquals;
    import static org.junit.jupiter.api.Assertions.assertTrue;

    @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
    @TestPropertySource(properties = {
            "paralife.tick.auto-start=false",
            "paralife.world.width=16",
            "paralife.world.height=16"
    })
    class WebSocketDeflateHandshakeIntegrationTest {

        @LocalServerPort
        private int port;

        @Test
        void serverNegotiatesPermessageDeflateWithNoContextTakeover() throws Exception {
            HttpClient http = HttpClient.newHttpClient();
            HttpRequest upgrade = HttpRequest.newBuilder(
                            URI.create("http://localhost:" + port + "/ws/world"))
                    .header("Connection", "Upgrade")
                    .header("Upgrade", "websocket")
                    .header("Sec-WebSocket-Version", "13")
                    .header("Sec-WebSocket-Key", "dGhlIHNhbXBsZSBub25jZQ==")
                    .header("Sec-WebSocket-Extensions",
                            "permessage-deflate; server_no_context_takeover")
                    .GET().build();

            HttpResponse<Void> resp = http.send(upgrade, BodyHandlers.discarding());

            assertEquals(101, resp.statusCode(), "Server should complete upgrade");
            String ext = resp.headers().firstValue("Sec-WebSocket-Extensions")
                    .orElseThrow(() -> new AssertionError("No Sec-WebSocket-Extensions response header"));
            assertTrue(ext.contains("permessage-deflate"),
                    "Response extensions missing permessage-deflate: " + ext);
            assertTrue(ext.contains("server_no_context_takeover"),
                    "Response extensions missing server_no_context_takeover: " + ext);
        }
    }

    ### `src/main/java/com/paralife/websocket/WebSocketRouteAssertion.java`
    ```java
    package com.paralife.websocket;

    import org.slf4j.Logger;
    import org.slf4j.LoggerFactory;
    import org.springframework.boot.context.event.ApplicationReadyEvent;
    import org.springframework.context.ApplicationContext;
    import org.springframework.context.event.EventListener;
    import org.springframework.stereotype.Component;
    import org.springframework.web.servlet.HandlerMapping;
    import org.springframework.web.socket.WebSocketHandler;

    import java.util.Map;
    import java.util.stream.Collectors;

    /**
     * Startup-time invariant check: exactly one WebSocket handler path at {@code /ws/world}.
     *
     * <p>Cross-AI review (2026-04-20, all three reviewers) flagged that pre-replan plans
     * included both a Spring-side registration AND a native Jetty {@code addMapping}
     * on the same path. The replan dropped the native path, but the invariant needs
     * runtime evidence — this bean provides it.
     */
    @Component
    public class WebSocketRouteAssertion {

        private static final Logger log = LoggerFactory.getLogger(WebSocketRouteAssertion.class);
        private static final String PATH = "/ws/world";

        private final ApplicationContext ctx;

        public WebSocketRouteAssertion(ApplicationContext ctx) {
            this.ctx = ctx;
        }

        @EventListener
        public void onReady(ApplicationReadyEvent event) {
            Map<String, HandlerMapping> mappings = ctx.getBeansOfType(HandlerMapping.class);
            long wsHandlers = mappings.values().stream()
                    .filter(hm -> describesPath(hm, PATH))
                    .count();

            // Also scan raw WebSocketHandler beans to cross-check — there MUST be exactly
            // one that downstream sends/receives reach.
            Map<String, WebSocketHandler> wsBeans = ctx.getBeansOfType(WebSocketHandler.class);
            String resolvedHandlers = wsBeans.entrySet().stream()
                    .map(e -> e.getKey() + "=" + e.getValue().getClass().getSimpleName())
                    .collect(Collectors.joining(", "));

            if (wsHandlers < 1) {
                throw new IllegalStateException(
                        "No handler registered for " + PATH + " — Phase 15 wiring invariant broken. "
                                + "WebSocketHandler beans: " + resolvedHandlers);
            }
            if (wsHandlers > 1) {
                throw new IllegalStateException(
                        "Multiple handlers registered for " + PATH + " (expected 1). "
                                + "WebSocketHandler beans: " + resolvedHandlers);
            }
            log.info("[ws-route-assertion] Confirmed single handler path {} — beans: {}",
                    PATH, resolvedHandlers);
        }

        private boolean describesPath(HandlerMapping hm, String path) {
            // Spring's default handler mapping exposes a property that includes
            // registered URL patterns. We accept any mapping whose toString/describe
            // includes the exact path token — this is a weak proxy but paired with
            // the companion integration test (WebSocketRouteAssertionTest) that
            // actually sends a frame through the route, it's sufficient to detect
            // the "zero or multiple" failure modes.
            String desc = hm.toString();
            return desc != null && desc.contains(path);
        }
    }
    ```

    ```java
    package com.paralife.websocket;

    import org.junit.jupiter.api.Test;
    import org.springframework.beans.factory.annotation.Autowired;
    import org.springframework.boot.test.context.SpringBootTest;
    import org.springframework.boot.test.web.server.LocalServerPort;
    import org.springframework.test.context.TestPropertySource;
    import org.springframework.web.socket.TextMessage;
    import org.springframework.web.socket.WebSocketHandler;
    import org.springframework.web.socket.WebSocketSession;
    import org.springframework.web.socket.client.jetty.JettyWebSocketClient;
    import org.springframework.web.socket.client.WebSocketClient;
    import org.springframework.web.socket.handler.AbstractWebSocketHandler;

    import java.net.URI;
    import java.util.concurrent.CountDownLatch;
    import java.util.concurrent.TimeUnit;

    import static org.junit.jupiter.api.Assertions.assertTrue;

    @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
    @TestPropertySource(properties = {
            "paralife.tick.auto-start=false",
            "paralife.world.width=16",
            "paralife.world.height=16"
    })
    class WebSocketRouteAssertionTest {

        @LocalServerPort int port;
        @Autowired WebSocketRouteAssertion assertion;
        @Autowired WorldWebSocketHandler handler;

        @Test
        void exactlyOnePathReachesHandleTextMessage() throws Exception {
            // The WebSocketRouteAssertion bean has already run at ApplicationReadyEvent
            // (autowired non-null => startup completed without IllegalStateException).
            assertTrue(assertion != null, "Assertion bean should exist");

            // Send a live malformed frame through the upgraded connection. A malformed
            // frame guarantees the handler's handleTextMessage path runs (it will
            // respond with E|400 via PerceptionCodec; we only care that the path ran).
            WebSocketClient client = new JettyWebSocketClient();
            CountDownLatch replyLatch = new CountDownLatch(1);
            WebSocketHandler probeHandler = new AbstractWebSocketHandler() {
                @Override
                public void afterConnectionEstablished(WebSocketSession session) throws Exception {
                    session.sendMessage(new TextMessage("GARBAGE"));
                }
                @Override
                protected void handleTextMessage(WebSocketSession session, TextMessage message) {
                    replyLatch.countDown();
                }
            };

            URI uri = URI.create("ws://localhost:" + port + "/ws/world");
            WebSocketSession session = client.doHandshake(probeHandler, uri.toString()).get(5, TimeUnit.SECONDS);

            boolean gotReply = replyLatch.await(5, TimeUnit.SECONDS);
            session.close();
            assertTrue(gotReply, "Probe handler did not receive any server reply — frame did not reach WorldWebSocketHandler");
        }
    }
    ```
