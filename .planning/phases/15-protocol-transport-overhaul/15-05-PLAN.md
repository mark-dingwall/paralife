    ```java
    package com.paralife.codec;

    import java.util.ArrayList;
    import java.util.List;
    import java.util.Optional;
    import java.util.OptionalInt;

    public final class PerceptionCodec {

        public static final int MAX_S_ENTRIES = 256;
        public static final int MAX_V_ENTRIES = 32;

        private PerceptionCodec() {}

        // ============ ENCODE ============

        public static String encode(Frame f) {
            StringBuilder sb = new StringBuilder(128);
            switch (f) {
                case Frame.TickFrame t -> encodeTick(sb, t);
                case Frame.SyncFrame s -> encodeSync(sb, s);
                case Frame.RegisterFrame r -> encodeRegister(sb, r);
                case Frame.ActionFrame a -> encodeAction(sb, a);
                case Frame.ErrorFrame e -> encodeError(sb, e);
            }
            return sb.toString();
        }

        // ============ DECODE ============

        public static Frame decode(String s) {
            if (s == null || s.isEmpty()) {
                throw new CodecException("Empty input");
            }
            ParseCursor c = new ParseCursor(s);
            char type = c.next();
            return switch (type) {
                case 'T' -> { c.expect('|'); yield parseTick(c); }
                case 'S' -> { c.expect('|'); yield parseSync(c); }
                case 'r' -> { c.expect('|'); yield parseRegister(c); }
                case 'a' -> { c.expect('|'); yield parseAction(c); }
                case 'E' -> { c.expect('|'); yield parseError(c); }
                default -> throw new CodecException("Unknown frame type: " + type);
            };
        }

        // --- private encode/decode helpers below ---
    }
    ```

    Implement helpers below, one method per block / frame type. Key rules from SCHEMA:

    **§2 coord encoding (single-form):**
    - `encodeAbsolute(sb, int x, int y)`: emit `base64(x>>6) base64(x&63) base64(y>>6) base64(y&63)` → 4 chars. Decode reverses.
    - `encodeRelative(sb, int dx, int dy)`: emit `sign(dx) base64(abs(dx)) sign(dy) base64(abs(dy))` → **exactly 4 chars**. Decode reverses. There is NO 6-char "extended relative" form — dx/dy are always a single base64 char per axis. If an encoder gets asked to emit a relative coord whose magnitude exceeds 63, clamp to ±63 (per SCHEMA §8.4 lightning-coord-range note) and log; do NOT widen the wire form.
    - `encodeNumpad(sb, char digit)`: emit digit directly.

    **§6.3 T header positional slots (always present):**
    ```
    T|<tickId:4>|<curX:2><curY:2>|<energy>/<maxEnergy>|<sensorRadius:1>
    ```
    - tickId: 4 unsigned base64 chars.
    - curX/curY: 2 unsigned base64 chars each, concatenated as 4-char absolute.
    - energy, maxEnergy: variable-length base64 unsigned integers (read until `/` or `|`).
    - sensorRadius: 1 base64 char.

    §6.3.2 minimal form detection: minimal `T` has four `|`-separated positional slots (tickId, curXcurY, energy/max, events-or-end) — i.e. no sensor-radius digit. Detect by reading three mandatory slots, then peeking; if next char is `v`, this is minimal form (event block follows immediately). Encode minimal by setting `sensorRadius=0`.

    **§8.1 `s` block (coord-first, presence bitmask) — bounded entries:**
    Parsing per-entry (in a loop; track entries read against `MAX_S_ENTRIES`):
    1. Peek first char: digit `1`-`9` → numpad (consume 1); `+`/`-` → relative (consume 4 — always 4, never 6); letter → error (`s` entries always have coord per §8.1).
    2. Consume presence char (base64 digit): value ∈ {1,2,3}.
    3. If presence bit 0 set:
       - Read kind char. If kind == 'R':
         - Peek next. If next char is digit → RLE (run) direction; else solo.
         - RLE: consume direction digit (1..9, not 5), then consume count (1 base64 char = 1..63).
       - Else: Simple kind code.
    4. Determine remaining chars before next `,` or end-of-block (parser look-ahead table §8.1.4).
    5. Before appending to the cell list, check `if (cells.size() >= MAX_S_ENTRIES) throw new CodecException("MAX_S_ENTRIES exceeded at " + cursor.index());`.

    **§8.2 `c` block (single token):**
    `c<code>[:<ctx>]` — code is one of C/M/S/D/N/T/0/1/2/3/4/5/Z. ctx is substring until next `|` or end-of-frame.

    **§8.3 `f` block:**
    Each entry: `<code>:<expiryTick:4>[:<ctx>]`. ctx for FLEEING is `XXYY` abs (4 chars). Entries separated by `,`.

    **§8.4 `v` block (bounded entries):**
    Per entry, parser rule:
    1. First char digit → numpad coord (consume 1).
    2. First char `+`/`-` → relative coord (consume 4 — always 4, never 6).
    3. First char letter → no coord.
    4. Read code (1 char). Per SCHEMA §8.4 table, consume magnitude (1 base64 char) iff code ∈ {E, A, H, T, M, R, L}.
    5. Before appending, check `if (events.size() >= MAX_V_ENTRIES) throw new CodecException("MAX_V_ENTRIES exceeded at " + cursor.index());`.

    Codes with coord: E/A/H/L/N take source/target/attacker/strike/alarming-member cell (rel or numpad). T/M/R/S/D have no coord. Parser rule above handles the leading-char check; then magnitude rule applied per code.

    Vector 9 parse verification: `v+F-3L5` → consume `+` → relative; read 4 chars total (`+F-3`); dx = +15 (base64 F), dy = -3 (base64 3). Then code `L`, magnitude `5` (base64 5). One event, one coord, one magnitude — LL(1) clean.

    **§8.5 `g` block:**
    Entries: `<coord><role>` — coord is 1-char numpad OR 4-char relative (first-char rule). role is '0'-'5'. Entries separated by `,`.

    **§6.1/§6.4 simple frames:**
    - Register: `r|<C/M/S>`.
    - Action: `a|<verb>[|<arg>]`. Verbs M/E/A/R take single numpad digit arg. V takes 3-char numpad string. L has no arg.
    - Error: `E|<code:3 decimal>[|<msg>]`.

    **§6.2 S frame:**
    `S|<entityId>[|<activeEffects>]` — entityId is base64 string, terminated by `|` or end. Effects segment uses same shape as `f` block entries (no `f` prefix).

    **Error handling:**
    - Every parse failure throws `CodecException` with a message including the cursor index and a brief reason.
    - Unknown leading char → `CodecException("Unknown frame type: X")`.
    - Short input / unexpected end → `CodecException("Unexpected end of input at N")` (ParseCursor already does this).
    - Out-of-alphabet char → propagated via `Base64Codec.decodeDigit`.
    - Bounded-entries violation → `CodecException` with "MAX_S_ENTRIES" or "MAX_V_ENTRIES" literal in the message.

    **Zero-trust invariant:** the codec encodes CellEntry objects that carry `kind` and `presence` but ZERO occupant id. The decoder never produces any entity-id. The ZeroTrustFilteringTest in plan 15-08 verifies this on real broadcaster output.

    **Performance:** Use `StringBuilder` for encode (pre-sized ~128); use `ParseCursor` for decode (single-pass). No `split()`. No regex.

    Full implementation is substantial (~500-700 lines). Code can be organised with private helpers: `encodeSBlock`, `encodeFBlock`, `encodeVBlock`, `encodeGBlock`, `encodeCBlock`, `parseSBlock`, etc.

    import org.junit.jupiter.api.Test;

    import java.util.Optional;

    import static org.junit.jupiter.api.Assertions.assertEquals;
    import static org.junit.jupiter.api.Assertions.assertThrows;
    import static org.junit.jupiter.api.Assertions.assertTrue;

    /** Negative-path tests for PerceptionCodec — malformed wire → CodecException. */
    class PerceptionCodecErrorTest {

        @Test
        void emptyInputRejected() {
            assertThrows(CodecException.class, () -> PerceptionCodec.decode(""));
        }

        @Test
        void nullInputRejected() {
            assertThrows(CodecException.class, () -> PerceptionCodec.decode(null));
        }

        @Test
        void unknownFrameTypeRejected() {
            CodecException ex = assertThrows(CodecException.class,
                    () -> PerceptionCodec.decode("Z|whatever"));
            assertTrue(ex.getMessage().contains("Unknown frame type"), ex.getMessage());
        }

        @Test
        void outOfAlphabetCharRejectedInHeader() {
            assertThrows(CodecException.class,
                    () -> PerceptionCodec.decode("T|!!!|0A1B|15/80|2"));
        }

        @Test
        void truncatedTickRejected() {
            assertThrows(CodecException.class,
                    () -> PerceptionCodec.decode("T|001|0A"));
        }

        @Test
        void unknownActionVerbRejected() {
            assertThrows(CodecException.class,
                    () -> PerceptionCodec.decode("a|Q|8"));
        }

        @Test
        void actionRoundTrips() {
            Frame.ActionFrame move = new Frame.ActionFrame('M', Optional.of("8"));
            String encoded = PerceptionCodec.encode(move);
            assertEquals("a|M|8", encoded);
            Frame decoded = PerceptionCodec.decode(encoded);
            assertEquals(move, decoded);
        }

        @Test
        void alarmActionRoundTrips() {
            Frame.ActionFrame alarm = new Frame.ActionFrame('L', Optional.empty());
            String encoded = PerceptionCodec.encode(alarm);
            assertEquals("a|L", encoded);
        }

        @Test
        void errorFrameRoundTrips() {
            Frame.ErrorFrame e = new Frame.ErrorFrame(429, Optional.of("respawn cap"));
            String encoded = PerceptionCodec.encode(e);
            assertEquals("E|429|respawn cap", encoded);
            Frame decoded = PerceptionCodec.decode(encoded);
            assertEquals(e, decoded);
        }

        @Test
        void registerFrameRoundTrips() {
            Frame.RegisterFrame r = new Frame.RegisterFrame('C');
            assertEquals("r|C", PerceptionCodec.encode(r));
            assertEquals(r, PerceptionCodec.decode("r|C"));
        }

        @Test
        void largeInputRejectedQuickly() {
            String bomb = "T|" + "x".repeat(100_000);
            long start = System.nanoTime();
            try {
                PerceptionCodec.decode(bomb);
            } catch (CodecException ignored) {
                // expected — parser rejects malformed bytes

            long elapsedMs = (System.nanoTime() - start) / 1_000_000L;
            assertTrue(elapsedMs < 500,

            for (int i = 0; i < 10_000; i++) {
                if (i > 0) bomb.append(',');
                bomb.append("61F");

                    () -> PerceptionCodec.decode(bomb.toString()));
            assertTrue(ex.getMessage().contains("MAX_S_ENTRIES"),
                    "Expected MAX_S_ENTRIES in message: " + ex.getMessage());

            assertTrue(ex.getMessage().contains("MAX_V_ENTRIES"),
                    "Expected MAX_V_ENTRIES in message: " + ex.getMessage());
        }
