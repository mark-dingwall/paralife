    - Each LOCOMOTOR member submits ranked direction preferences (max 3) via CompositeAction.rankedPreferences
    - First-preference plurality with random tie-break (simplified STV per research recommendation)
    - If no LOCOMOTOR members exist, composite is sessile (D-22)

    - speed = locomotor_count / colony_size * speedConstant

    - speed < 1.0: composite can only move every ceil(1/speed) ticks. Track "ticks since last move" per composite.

    Rigid body movement (D-24):
    - All members shift in the winning direction
    - Blocked if ANY member's target cell is occupied (by non-member entity or Rock)
    - Uses claimedCells set — all target cells claimed atomically before executing moves
    - After movement, update all member positions in BotRegistry and CompositeRegistry

    - Collect all LOCOMOTOR votes per composite
    - Count first preferences, random tie-break

    - Check all target cells unoccupied and unclaimed

    ```java
    private Direction resolveLocomotorVote(List<List<String>> rankedVotes) {
        // Count first preferences
        Map<Direction, Integer> counts = new EnumMap<>(Direction.class);
        for (List<String> prefs : rankedVotes) {
            if (!prefs.isEmpty()) {
                Direction d = Direction.fromString(prefs.get(0));
                if (d != null) counts.merge(d, 1, Integer::sum);
            }
        }
        if (counts.isEmpty()) return null;
        // Find max, break ties randomly
        int max = Collections.max(counts.values());
        List<Direction> winners = counts.entrySet().stream()
            .filter(e -> e.getValue() == max)
            .map(Map.Entry::getKey).toList();
        return winners.get(ThreadLocalRandom.current().nextInt(winners.size()));
    }
    ```

    ```java
    int locomotorCount = countLocomotors(composite);
    int colonySize = composite.getMemberIds().size();
    double speed = (double) locomotorCount / colonySize * compositeConfig.speedConstant();
    int moveInterval = speed >= 1.0 ? 1 : (int) Math.ceil(1.0 / speed);
    int ticksSince = compositeTicksSinceMove.getOrDefault(compositeId, moveInterval); // allow first move
    if (ticksSince < moveInterval) {
    ```

    ```java
    private boolean resolveCompositeMovement(String compositeId, Direction dir,
            CompositeRegistry.CompositeState composite, Set<Position> claimedCells) {
        // Calculate all target positions
        List<Position> currentPositions = getMemberPositions(composite);
        List<Position> targetPositions = currentPositions.stream()
            .map(p -> dir.apply(p, worldGrid.getWidth(), worldGrid.getHeight()))
            .toList();

        // Check ALL targets unoccupied and unclaimed
        for (Position target : targetPositions) {
            if (claimedCells.contains(target)) return false;
            Cell tc = worldGrid.getCell(target.x(), target.y());
            if (tc.hasOccupant()) {
                // Allow if occupant is a member of this same composite
                if (tc.occupant() instanceof Entity.CompositeMember cm && cm.compositeId().equals(compositeId)) continue;
                return false;
            }
        }

        // Claim all targets
        claimedCells.addAll(targetPositions);

        // Execute: clear source, place at target
        List<Entity.CompositeMember> members = getMembersFromGrid(composite);
        for (int i = 0; i < currentPositions.size(); i++) {
            worldGrid.clearEntity(currentPositions.get(i).x(), currentPositions.get(i).y());
        }
        for (int i = 0; i < targetPositions.size(); i++) {
            worldGrid.setEntity(targetPositions.get(i).x(), targetPositions.get(i).y(), members.get(i));
            // Update BotRegistry
            String memberId = members.get(i).id();
            botRegistry.getSessionForEntity(memberId).ifPresent(sid ->
                botRegistry.updatePosition(sid, targetPositions.get(i)));
        }
        // Update CompositeRegistry positions
        compositeRegistry.updateMemberPositions(compositeId, targetPositions);

        // Charge LOCOMOTOR active drain
        int locomotorCount = countLocomotors(composite);
        composite.drainEnergy(locomotorCount * compositeConfig.locomotorActiveDrain());

        compositeTicksSinceMove.put(compositeId, 0);
        return true;
    }
    ```
