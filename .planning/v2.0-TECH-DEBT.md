# v2.0 Tech Debt Log

Deferred items surfaced during phase reviews. Each carries a rationale
for deferral plus a trigger condition that should promote it to active
work. Closed items stay listed with a reference to the commit that
resolved them.

## Phase 13 deferrals (triage 2026-04-15)

### DF-A — BondedPair speculative cached fields

**Source:** Cross-AI review (Codex concern D).
**What:** `Entity.BondedPair.effectiveCombatTransfer` and
`effectiveAttackPower` are computed at bond formation but never read —
BondedPairs today are passive during combat.
**Why defer:** These fields document the future-intended wiring for
active-agency BondedPairs. Deleting now means re-adding later. No
correctness impact.
**Trigger:** Promote when BondedPairs become actionable agents (phase
that gives them per-tick actions or delegated control).

### DF-B — MetabolismIntegrationTest weakness

**Source:** Cross-AI review (Codex concern C).
**What:** `MetabolismIntegrationTest` uses `Thread.sleep`-driven
sampling, a qualitative seasonal check, and no
`bondedPairObserved` assertion. Not tagged slow / integration-only.
**Why defer:** Test passes today and exercises the full 4-phase tick
pipeline end-to-end. Strengthening assertions is a testing-quality
pass, not a correctness fix.
**Trigger:** Promote on first flake in CI, or when moving tests to a
staged fast/slow split.

### DF-C — Hybrid vigor integer truncation

**Source:** Internal review (IN-01).
**What:** For near-equal parent rates (e.g. 3 and 4) all hybrid-vigor
bonus multipliers truncate to zero due to integer math.
**Why defer:** Behavior is defensible — near-identical parents produce
no vigor. Fix requires promoting fields to float on a record used in
many hot paths.
**Trigger:** Promote if balancing reveals bond pairs are systematically
indistinguishable from solo parents.

### DF-D — Composite attacker break-on-first-neighbour

**Source:** Internal review (IN-03).
**What:** Non-ATTACKER composite members break after the first
non-prey neighbour check, biasing outcomes toward neighbour-iteration
order.
**Why defer:** Likely intentional ("one action per tick"). Design
intent undocumented; no current complaint from behavior observation.
**Trigger:** Promote during composite combat balance tuning, or when a
test ranks adjacent-enemy selection against spatial distribution.

### DF-E — Synthetic wire-format type strings

**Source:** Internal review (IN-06).
**What:** `CellView.occupantType` uses synthetic concatenated strings
(`"BONDED_CATALYST_MEMBRANE"`, `"COMPOSITE_SPORE_FEEDER"`). Clients
that need to discriminate must string-prefix-match.
**Why defer:** Only one client (bots via raw JSON). Restructuring to
`{type, subtype, role}` is a breaking wire change.
**Trigger:** Promote when a second consumer appears, or when
string-parsing in a bot causes a correctness bug.

### DF-F — Cell.nutrientLevel regeneration / decay

**Source:** Cross-AI review (Codex concern G).
**What:** `Cell.nutrientLevel` stays at its seed value forever — no
regen, no decay. Fertile patches remain fertile permanently; consumed
patches never recover.
**Why defer:** Phase 13 explicitly scoped to "initial patches +
seasonal multiplier". Ecology will reveal whether regen is needed;
premature now.
**Trigger:** Promote when ecology observation shows fertile patches
becoming dead zones or one-shot spawners skewing population dynamics.
