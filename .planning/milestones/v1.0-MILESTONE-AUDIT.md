## Critical Findings (Resolved)

### 1. Cell Flags Environmental Effect — RESOLVED 2026-04-12

Implemented overcrowding environmental effect:
- `Cell.FLAG_OVERCROWDED = 1` added
- `SimulationEngine.processOvercrowding()` iterates grid, counts particle neighbors, applies energy penalty when count >= configurable threshold
- `FLAG_OVERCROWDED` flag set/cleared on cells to reflect current state
- Configurable via `overcrowding-threshold` (default 6) and `overcrowding-energy-penalty` (default 2) in application.yml
- 4 unit tests verify: penalty applied, no penalty below threshold, flag set/cleared, overcrowding causes death

### 2. Entity Death BotRegistry Cleanup — RESOLVED 2026-04-12

- `BotRegistry` injected into `SimulationEngine` via constructor
- `processDeaths()` now calls `botRegistry.unregisterByEntity(p.id())` before clearing the grid cell
- 2 unit tests verify: death triggers unregister, alive particle does not
