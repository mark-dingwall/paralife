# T01: Gradle project + Spring Boot application

**Slice:** S01
**Milestone:** M001

## Goal
Create a bootable Spring Boot 3.x application with Java 21, Gradle Kotlin DSL, and all M1 dependencies.

## Must-Haves

### Truths
- `./gradlew bootRun` starts and logs "Started ParalifeApplication"
- Java 21 language features available (records, virtual threads)
- `spring.threads.virtual.enabled=true` in config

### Artifacts
- `build.gradle.kts` — Spring Boot 3.4.x, Java 21, deps: spring-boot-starter-web, spring-boot-starter-websocket, spring-boot-starter-actuator, spring-boot-starter-test
- `settings.gradle.kts` — project name "paralife"
- `src/main/java/com/paralife/ParalifeApplication.java` — `@SpringBootApplication` main class
- `src/main/resources/application.yml` — virtual threads, server port, app name

## Steps
1. Create `settings.gradle.kts` with project name
2. Create `build.gradle.kts` with Spring Boot plugin, Java 21, all dependencies
3. Create `ParalifeApplication.java` with `@SpringBootApplication` and main method
4. Create `application.yml` with virtual threads enabled
5. Run `./gradlew build` to verify compilation
6. Run `./gradlew bootRun` briefly to verify startup

## Context
- Using Spring Boot 3.4.x (latest stable) with Java 21
- Virtual threads enabled via `spring.threads.virtual.enabled=true` per Spring Boot 3.5 docs
- Gradle wrapper will be generated by `gradle wrapper`
